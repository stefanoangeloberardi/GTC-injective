Consider the following strongly connected *strict* SCT-instance {f,g}
 • G1:f-->f, G2:f-->g, G3:g-->f, G4:g-->g
 • Var(f)=Var(g)={x,y}
 • G1={x-->x}, G2={x-->y}, G3={y-->x}, G4={y-->y}
 • We assume that all arrows in all graphs are *strictly* progressing

 The SCT-instance is composition-closed. There are eight correct compositions and 
we have:

G1G1=G1:f-->f 
G1G2=G2:f-->g

G2G3=G1:f-->f
G2G4=G2:f-->g

G3G1=G3:g-->f
G3G2=G4:g-->g

G4G3=G3:g-->f
G4G4=G4:g-->g

 SCT holds: if G:f-->f or G:g-->g then G=G1 and x-->x∈G progresses
to itself, or G=G4 and y-->y∈G progresses to itself.

 Alternatively, we can check SCT directly. By induction on the path, we can prove that 
in every finite path from f there is exactly one thread from x in the path and that 
in every finite path from g there is exactly one thread from y in the path. 
This implies that every infinite path has exactly one infinite thread, progressing 
at each step.

 Thus, this SCT-instance satisfies SCT, it is strict and it is fan-out free:
there is at most one image for each variable x,y in all graphs.

 By Lemma 3.4, page 10 of the paper: RANKING FUNCTIONS FOR SIZE-CHANGE TERMINATION II,
there some non-empty thread-preserver P. Then x∈P or y∈P.
 • If x∈P then x in Var(f)∩P, therefore there is some z∈P such that
   x-->z ∈ G1:f-->g. Necessarily z=y, hence y∈P.
 • If y∈P then y∈Var(g)∩P, therefore there is some z∈P such that
   y-->z ∈ G3:f-->g. Necessarily z=x.
Thus, if the thread-preserver P is not empty then P={x,y}.

 But this is a contradiction. We have y∈Var(f)∩P, however there is no z∈P such that
y-->z ∈ G1:f-->g.

 ANSWER from Amir M. Ben-Amram Wed, 5 Mar 2025 at 10:19

 Dear Stefano,

 The answer to this apparent contradiction is simple: the variables have to be renamed 
so that they are unique across the graph. For instance, they can be named xf, yf, xg, yg.  
Then you get the thread preserver {xf, yg}.

 Best regards,
 Amir

Your impression is not true in general. Here is a counter-example.
G1:f-->g = { x-->y, x-->z }     G2:g-->f = {y-->x}   G3:g-->f = {z-->x}

Lemma 3.4 (paper 2). Suppose that G is [strongly connected and] strict and fan-out free. 
Then G is size-change terminating if and only if G has a non-empty thread-preserver.
-------------------------------------------------------------------------------------------
In in order to prove Lemma 3.4 I prove first:
(my Lemma) Every non-empty thread-preserving P in a strongly connected graph G intersects Var(f)
for all f in G. 

(my Proof). If P is not empty, then there is some x in P/\Var(g) for some g in G. Since G
is strongly connected there is a path from g to f, namely some G1:f_0-->f_1,..., Gn:f_{n-1}-->f_n 
with g=f_0 and f_n=g. Since P is thread-preserving and x in P/\Var(g) there is a sequence 
x=x_0 G1 x_1 ... x_{n-1} G_n x_n all included in P. In particular we have x_n in P/\Var(f_n) = 
P/\Var(f). We conclude that P intersects Var(f).

(my corollary) If P is non-empty thread-preserving and G is strongly connected and strict, then SCT holds.
(my Proof). Assume f_0,f_1,f_2,... is any infinite path in G. By (my Lemma) there is some x in P/\Var(f_0).
Since P is thread-preserving there is an infinite trace/thread x=x_0 G1 x_1 ... x_{n-1} G_n x_n ... all included 
in P. Since G is strict then this infinite trace is progressing at each step. Thus, SCT holds.

-------------------------------------------------------------------------------------------
As a corollary of the corollary, convergence follows by a unary induction on the sum of values of P/\Var(f).
-------------------------------------------------------------------------------------------

Lemma 3.4 (paper 2). Suppose that G is [strongly connected and] strict and fan-out free. 
Then G is size-change terminating if and only if G has a non-empty thread-preserver.

(my proof).
==>. In (my corollary) we proved right-to-left: P is non-empty thread-preserving ==> G is size-change terminating.

<==. Now we assume that: G is size-change terminating, in order to prove that: there is some 
non-empty thread-preserving P. 
By renaming, we can assume that the set Var(f) are pairwise disjoint for each f in G.

Let Q0 be the set y in Var(g) such that for some G:g-->h there is no y-->z in G. Let Q be the set of x in some
Var(f) such that there is a trace from x to y. Let P = U_f Var(f) \ Q. P is thread preserving: if G:f-->g
and y-->x in G then there y is not in Q, otherwise x would be in Q. We prove that P is not empty by contradiction.
We assume that P is empty and we prove that there is some multipath with no infinite progressing trace.
We start from any f and we choose any x in Q/\Var(f). By definition of Q, there is some multipath from f to some g 
and some y in Q0/\Var(g) such that if we move to some h then the unique trace from x ends in y. We move to h,
then we can move back from h to f by strong connection: there is no trace from x to any element of Var(f) 
in the multipath, and any element of Var(f) has at most one image in the multipath. therefore some x_1 in Var(f) 
is not reachable from any element of Var(f) in the multipath. We choose any x' in Var(f) different from x_1 such that
there is some trace to x' in the multipath, and we find another multipath from f to f such that there is no trace from x'. 
At each step we reduce by 1 the number of images of the elements of Var(f), until we reach zero. If we repeat cyclically 
this multipath from f to f no trace can continue from the beginning to the end of one of these cycles, therefore
there is no infinite trace in this infinite multipath.
