\section{Introduction}
Global Trace Condition (from now on, GTC) implies correctness for a cyclic proof.
We want to find a proof of this fact that the  which is both intuitionistic, 
first order arithmetical and with human-readable intermediate step.  

Cyclic proofs are an interesting tool for proof search and have been introduced as
by Brotherston and Simpson (\cite{BrotherstonSimpson}).
They have been efficiently implemented 
(\cite{10.1007/978-3-642-35182-2_25,10.1145/3632888, 10.1007/978-3-031-90643-5_18,  10.1145/3453483.3454087,  10.1145/3018610.3018623, Stratulat_2021, Brotherston2020}).
by Brotherston and Simpson \cite{BrotherstonSimpson}. 
Later, the algorithm checking correctness for cyclic proofs turned out to be
a particular case of the algorithm checking the 
\emph{algorithm condition for Size Change Termination} condition for programs. 

The \emph{algorithm condition for Size Change Termination}
(from now on, $\SCTa$ for short) was introduced by
Chin Soon Lee, Neil D. Jones and Amir M. Ben-Amram in \cite{Lee1}, 
\S 3.2, Theorem 4. The proof that Global Trace Condition implies correctness 
can be seen as a particular of this Theorem. We are interested to find
an intuitionistic, first order and human-readable alternative proof of this result. 

The name \quotationMarks{$\SCTa$} for the condition of Theorem 4 is ours, 
this condition has no name in \cite{Lee1}.
$\SCTa$ was introduced in order to prove program termination: 
we formally define $\SCTa$ in the next section.
In our paper, we are interested to $\SCTa$ in a particular case which is relevant for cyclic proofs:
we are interested to the case of transition multi-graphs labeled by 
\emph{injective} bi-colored relations. This condition is called 
the \emph{fan-in-free} condition in \cite{Lee2}.

As we said, our motivation is that this particular case of $\SCTa$ is enough to check 
the correctness of cyclic proofs.

\begin{definition}[Multigraphs]
\label{definition-multigraph}
Suppose be given:

\begin{enumerate}
\item
a \emph{finite set} $X = \{ x_1, \ldots, x_n \} $
 (it could represent parameters of a proof or variables of a program);

\item
A finite set $V$ of vertices
 (it could represent judgment of a cyclic proof or abstract program states).

%\item
%a finite set $\setR \subseteq \setP(X^2)^2$, with
%each $(\Stat, \Prog) \in \setR$ a \emph{pair of finite relations on $X$}
%such that \emph{$\Stat \cap \Prog = \emptyset$ for all $(\Stat, \Prog) \in \setR$},
%and representing bi-partite graphs (i.e., bi-colored relations) on $X$.
%We call each $(\Stat, \Prog) \in \setR$ just a \emph{pair} for short.

\item
a finite set 
$E \subseteq V \times \setP(X^2)^2 \times V$ of labeled edges,
with each edge including two disjoint relations:
 \emph{$\Stat \cap \Prog = \emptyset$ for all $(a,(\Stat, \Prog),b) \in E$}
\end{enumerate}

The we call $\setG= (V,E,X)$ a multigraph. We introduce the following abbreviations:

\begin{enumerate}
\item
For any $e = (a, (\Stat, \Prog), b) \in E$ we set  
$\dom(e) = a$, $\Label(e) = (\Stat, \Prog)$ and $\codom(e) = a$.

\item
We write $\setR = \Label(E)$ for the set of pairs $(\Stat, \Prog)$ 
labeling the edges of $\setG$.
\end{enumerate}
\end{definition}

$\setG=(V,E,X)$ is a labeled graph, and the labels $e = (a, (\Stat, \Prog), b) \in E$ of each edge
define a bi-colored graph on $X$, with $\Stat$ the set of edges of the first color, called
stationary or weakly progressing, and $\Prog$ the set of edges of the second color,
called strictly progressing or just progressing.
Following Neil Jones, we call $\setG$ a multi-graph.

If $x \Stat y$ (if the edge from $x$ to $y$ has the stationary color)
we say that $x$ weakly progresses to $y$ in $(\Stat, \Prog)$, and we mean that $x \ge y$.
If $x \Prog y$ (if the edge from $x$ to $iy$ has the progressing color)
we say that $x$ progresses to $y$ in $(\Stat, \Prog)$, and we mean that $x > y$.
Each labeled edge $e = (a, (\Stat, \Prog), b) \in E$ represents all
we assume about the relationship between the values of any two variables $x$, $y$ before
and after some possible transition of a program from state $a$ to state $b$: 
either weak progression, or strict progression, 
or no information at all, in the case $x \Stat y$ and $x \Prog y$ are both false.

We define composition of pairs in $\setR$ by saying that a composition is weakly
progressing if can be obtained by composing a pair of weakly progressing edges,
and \emph{only in this way};
and that it is strictly progressing if it can be obtain by composing a pair of edge including
some strictly progressing pair, in at least one way.
$$
\Stat'' = \Stat \Stat', 
\ \ \ 
\Prog'' = \Stat \Prog' \cup \Prog \Stat' \cup \Prog \Prog'
$$
$$
(\Stat,\Prog)(\Stat',\Prog') 
=
(\Stat''\setminus\Prog'', \Prog'')
$$
By definition, the result of composition is a \emph{disjoint} 
pair of finite relations on $X$, therefore again a bicolored relation.
Two pairs $(\Stat, \Prog), (\Stat', \Prog') \in \setR$ are composable
if we have $(a, (\Stat, \Prog), b), (b, (\Stat', \Prog'), c) \in E$ for some $a,b,c \in V$.
namely, if $(\Stat, \Prog), (\Stat', \Prog')$ label some transition sequence in the
multi-graph $\setG$.


\begin{definition}[Composable pairs  in $\setG$]
Assume $\setG=(V,E,X)$ is a multigraph  (Def. \ref{definition-multigraph}).

\begin{enumerate}

\item
$E^+$ is the smallest ternary relation including $E$ and closed
by domain-compatible composition: 
if $(a,(\Stat,\Prog),b),  (b,(\Stat,\Prog),c)\in E^+$ then  
$(a,(\Stat,\Prog)(\Stat',\Prog'),c) \in E^+$.

We write $\setG^+$ for the multigraph $(V,E^+,X)$.

\item
We write  $\composable{\setG}{a}{b}{(\Stat,\Prog)}$
for if $(a,(\Stat,\Prog),b) \in E^+$.

\item
We write 
$
\setR^\setG 
=  
\{(\Stat,\Prog) | \exists a,b \in V. \composable{\setG}{a}{b}{(\Stat,\Prog)} \}
$
for the set of bi-colored relations labeling some $e \in E^+$.

%\item
%We say that that two pairs of finite disjoint relations $(\Stat,\Prog), (\Stat',\Prog')$ on 
%$X$ are \emph{composable in $\setG$}, just \emph{composable} for short
%if and only if we have
%$\composable{\setG}{a}{b}{(\Stat,\Prog)}$ and
%$\composable{\setG}{b}{c}{(\Stat',\Prog')}$ for some $a,b,c, \in G$.

\item
A relation pair $(\Stat,\Prog) \in \setR^\setG$
is \emph{self-composable in $\setG$}, just \emph{self-composable}
for short, if and only if we have 
$\composable {\setG} {a} {a} {(\Stat,\Prog)}$ for some $a \in V$.

\end{enumerate}

\end{definition}

We are interested to a condition on $\setR, \setG$
called the \quotationMarks{Global Trace Condition} (GTC).
GTC is equivalent to the 
termination of value flows \quotationMarks{compatible}
with a path of $\setR, \setG$, as we will prove in Appendix.

GTC is expressed by saying that in all infinite path there is some trace compatible
with infinitely many elements related to the next element by the $\Prog$-part of
the trace.

\begin{definition}[Global Trace Condition (GTC) and Injectivity]
\label{definition-GTC-inj}
Assume $\setR, \setG$ are as in  Def. \ref{definition-multigraph}.
Suppose $X=\{x_1, \ldots, x_n\}$, $\setR =\{(\Stat_i, \Prog_i)| i \in [1,r]\}$
and $b, \tau$ are a path of $\setR, \setG$ and a trace, all of domain 
$D=[0,h]$ for some $h \in \N$ or $D=\N$.

\begin{enumerate}

\item
We say that the trace $\tau:D \rightarrow X$ is \emph{compatible} with the path
$b :D \rightarrow \setR$ on the same $D$, 
and we write $\tau \models b$, if and only if :
whenever $t, t+1 \in D$ and $b(t) = (a,(\Stat,\Prog),b) \in E$,
then the two consecutive elements  of the trace are related by $(\Stat,\Prog)$, namely
 $\tau(t) (\Stat \cup \Prog) \tau(t+1)$.
If $\tau(t) \Prog \tau(t+1)$,
we say that $t \in D$ is a \emph{$b$-progress point} of the trace $\tau$.

\item
$\setR,\setG$ satisfy the \emph{Global Trace Condition} (GTC) if and only if
for all infinite paths $b$ in $\setR,\setG$
there is some infinite trace $\tau:\N \rightarrow X$ such that
$\tau \models b$ and $\tau$ has infinitely many $b$-progress points.

\item
We write $\universe{(\Stat, \Prog)}
= \Stat \cup \Prog$ for the \emph{union} of the pair $(\Stat, \Prog) \in \setR$.


\item
$\setR$ satisfies \emph{injectivity} if and only 
the union relation $\universe{(\Stat, \Prog)}$ is injective
for all $(\Stat, \Prog) \in \setR$.

\end{enumerate}

\end{definition}

\begin{definition}[The SCT-a Algorithmic Condition]
\label{definition-SCT}
Assume $\setG=(V,E,X)$ is a labeled graph as in \ref{definition-multigraph} for some
finite set $X$.
We say that $\setG$ satisfies $\SCTa$ if and only if for all self-composable 
$\composable{\setG}{a}{a}{(\Stat,\Prog)}$ such that 
$(\Stat,\Prog) (\Stat,\Prog) = (\Stat,\Prog)$ there is some $x \in X$ such that $x \Prog x$.
\end{definition}

$\SCTa$ can be formulated in many equivalent way, for instance as Finite Power Condition (FPC):

\begin{definition}[Finite Power Condition (FPC)]
\label{definition-FPC}
$\setG$ satisfies FPC if and only if for all self-composable 
$\composable{\setG}{a}{a}{(\Stat,\Prog)}$ there is some $n > 0 $, some
$x \in X$ such that $x$ progresses to $x$ in $(\Stat,\Prog)^n$.
\end{definition}

For proving $\SCTa$ $\Leftrightarrow$ FPC we use a folk-lore
algebraic property, that all elements of all finite monoids have some positive idempotent power.

\begin{proposition}[Idempotent Power]
\label{proposition-idempotent-power}
If $M$ is a finite monoid and $x \in M$ then for some $n>0$ we have $x^nx^n=x^n$.
\end{proposition}

\begin{proof}
Since $M$ is finite, there are only finitely many powers of $x$, therefore 
for some $a,b>0$ we have $x^a = x^{a+b}$. Then for all $c \ge a$ we have $x^c = x^{c+b}$.
We deduce $x^c = x^{c+db}$ for all $d>0$. Take the first $d>0$ such that $db \ge a$,
and choose $c=db$: we conclude that 
$x^{db} = x^{db+db}$, for some $db >0$, as wished.
\end{proof}

\begin{proposition}[FPC and SCT-a are equivalent]
\label{proposition-SCT}
$\SCTa$ $\Leftrightarrow$ FPC
\end{proposition}

\begin{proof}
\begin{enumerate}
\item
Assume $\SCTa$, $\composable{\setG}{a}{a}{(\Stat,\Prog)}$ in order to prove that 
there is some $n > 0 $, some $x \in X$ such that $x$ progresses to $x$ in $(\Stat,\Prog)^n$.
By Prop. {proposition-idempotent-power} and finiteness of the bi-colored graphs on $X$
there is some $n > 0$ such that $(\Stat,\Prog)^n(\Stat,\Prog)^n=(\Stat,\Prog)^n$. By $\SCTa$,
there is some $x \in X$ such that $x$ progresses to $x$ in $(\Stat,\Prog)^n$.
\item
Assume FPC, $\composable{\setG}{a}{a}{(\Stat,\Prog)}$ and 
$(\Stat,\Prog)(\Stat,\Prog)=(\Stat,\Prog)$ in order to prove that 
there is some $x \in X$ such that $x$ progresses to $x$ in $(\Stat,\Prog)$.
By FPC, there is some $n > 0 $, some $x \in X$ such that $x$ progresses to $x$ in 
$(\Stat,\Prog)^n$. By $(\Stat,\Prog)(\Stat,\Prog)=(\Stat,\Prog)$ we deduce that 
$(\Stat,\Prog)^n=(\Stat,\Prog)$, hence $x$ progresses to $x$ in $(\Stat,\Prog)$.
\end{enumerate}
\end{proof}

Several decidable equivalent are known for GTC. In Classical Logic, GTC for 
$\setR,\setG$ is equivalent to the fact that all value flows compatible 
with some path are finite: we postpone the proof to the Appendix \ref{section-appendix}.

We assume injectivity and we are looking for an equivalent version
of GTC which can expressed in First Order Aritmetic, and such that
the finiteness of all compatible value flows can be proved
in Intuitionistic Arithmetic.

S. Berardi and M. Tatsuta proved that the equivalence between $\SCTa$ and GTC 
(already proved in \cite{Lee1}) is a corollary of Ramsey Theorem. 
We briefly recall this proof here.
In order to prove that $\SCTa \Rightarrow GTC$ 
we need the Infinite Ramsey Theorem, which we briefly recall here. 

We consider the graph $(\N,<)$ with set of vertices $\N$ and set of edges the order relation
$<$ on $\N$. A finite coloring of $(\N,<)$ is any function 
$f : \{(a,b) \in \N \times \N | a < b \}  \rightarrow \{1,...,c\}$, where $c$ is the number of colors. 

Infinite Ramsey Theorem says: for any finite coloring $f$, 
there exists an infinite subset $M\subseteq \N$ that is 
\emph{monochromatic}, that is, such that for some $i \in\{1,...,c\}$ and all $a,b \in M$,
$a<b$ we have $f(a,b)=i$. 

In our case the \quotationMarks{colors}
are in turn the set $\setG^\setR$ of bi-colored and oriented graphs 
$G = (\Stat,\Prog)$ on a finite set $X$, obtained by closing by composition
some set $\setG = (V,E)$ of multi-graphs.

\begin{proposition}
The Infinite Ramsey Theorem implies that $\SCTa \Rightarrow GTC$. 
\end{proposition}

\begin{proof}
Suppose we have an infinite path $\pi : \N \rightarrow E^+$ 
to find an infinitely progressing trace compatible with $\pi$. 
We choose as coloring for the pair $(i,j)\in \N \times \N$, $i<j$ 
the composition of multi-graphs between $i$ and $j$: we set 
$f(i,j) = \label(\pi(i)) \label(\pi(i+1)) \ldots \label(\pi(j))$. 
For Infinite Ramsey there exists an infinite set $M$ of indices $i_0 < i_1 < i_2 < \ldots$ 
and a "color" $(\Stat,\Prog)$ such that $f(i_k,i_h) = (\Stat,\Prog)$ 
for every k<h in NxN. In particular we have $f(0,1) = f(0,2) = f(1,2) = (S,P)$ by Ramsey

In this paper we are looking for a more
constructive and elementary proof of an equivalent result, 
namely the termination
of all value flows compatible with some path of $\setR$.
The proof should be suitable to a formalization in a proof assistant.
We add the injectivity assumption because relation pairs with
injectivity are enough to describe cyclic proofs, and if we have injectivity
proving a termination result requires a weaker hypothesis PDC (see below). 


The Progressing Domain Condition (PDC) says: 
\quotationMarks{all self-progressing $(\Stat,\Prog) \in \setR^\setG$ 
have a progression from $x$ to $y$ with both elements 
included in the domain of $(\Stat,\Prog)$}. Equivalenty, we can write PDC as
$$
\forall (\Stat,\Prog) \in \setR, a \in G. 
\ \ (\composable{\setG}{a}{a}{(\Stat,\Prog)}) \implies \exists x, y, z \in X. 
\ (x \Prog y) \wedge (y \Stat \cup \Prog z)
$$
PDC is weaker and it is easier to check than the $\SCTa$ condition. 

To check $\SCTa$, we have to check for any self-composable $(\Stat,\Prog) \in \setR^\setG$
whether $(\Stat,\Prog)$ is idempotent. If it is not idempotent, this is fine, if it is, we have to 
look for some $x$ progressing to itself in $(\Stat,\Prog)$.

In order to check PDC, instead, it is enough to find some $x$ progressing 
to some $y$, such that $y$ is weakly progressing or progressing to some $z$,
again in any self-composable $(\Stat,\Prog) \in \setR^\setG$.

Besides, using PDC it is faster to check whether a cyclic proof is correct.

However, PDC has the drawback that it implies 
GTC and termination only for \emph{injective} relation pairs. 
We explain why.

with \emph{injective} relation pairs

\item

if $\Card(X)=\Card(Y)$

\end{enumerate}

because $R$ is injective.

\end{enumerate}
\end{proof}

When for each $i \in[1,m]$  we have 
$\Card(\dom(R_{i,i})) = \Card(\dom(R_{i,i+1})) = \ldots = \Card(\dom(R_{i,l}))$ 
we say that the path $\pi$ has \emph{stable-cardinality}: the cardinality
of $\dom(R_{1,1})$ and $\dom(R_{2,2})$ can still be different.
When \emph{all} $\Card(\dom(R_{i,j}))$ are the same we
say that $\pi$ has constant-cardinality.

Here is the formal definition.


\begin{definition}
[Stable-Cardinality Path for a sequence on $E^+$]
Assume $\setG=(V,E,X)$ is a multigraph (\ref{definition-multigraph})
and $\pi:[1,l] \rightarrow E^+$ is any path on $\setG^+=(V,E^+,X)$
and $(\Stat_{i,j},\Prog_{i,j}) = (\Stat_i,\Prog_i) \ldots (\Stat_j,\Prog_j)$
and $R_{i,j} = \universe{(\Stat_{i,j},\Prog_{i,j})}$
for all $i,j \in[1,m]$, $i \le j$.


\begin{enumerate}

\item
$\pi$ has \emph{stable-cardinality} if and only if all $i \in[1,m]$ 
we have $\Card(\dom(R_i)) = \Card(\dom(R_{i,l}))$.

\item
$\pi$ has \emph{$k$-constant-cardinality} if and only if $k \le n$ and for all 
$i,j \in[1,m]$, $i \le j$ 
we have $\Card(\dom(R_{i,j})) = \Card(\dom(R_{1,l})) = k$.

\item
$\pi$ has \emph{constant-cardinality} if $\pi$ has $k$-constant-cardinality for some $k \le n$.

\item
$\pi$ is \emph{non-progressing} if and only if for all 
$i, j \in[1,m]$, $i < j$ we have $\neg (x \Prog_{i,j} y)$ for all 
$x \in \dom(\pi(i))$, $y \in \dom(\pi(j))$.
\end{enumerate}

\end{definition}

A path with non-progressing domains is a particulary unfavourable situation in which the
value of $\val(\dom(R_i),\sigma)$ could be not-decreasing.

\subsection{The Maximum Length of a non-Progressing constant-cardinality Path}
\label{subsection-constant-cardinality}

We want to estimate the maximum number of edges
we can have without a progress in a constant-cardinality path, given a multigraph 
which satisfies PDC. 

\begin{definition}[$\kappa(g,n,k)$]
Let $n,k \in \N$ with $1 \le n$ and $k \in [0,n]$.

\begin{enumerate}
\item
$\kappa(g,n,k)$ is the maximum $m \in \N$ such that there is
some multigraph $\setG=(V,E,X)$ with $g = \Card(V)$, $n=\Card(X)$
and which satisfies PDC,
and some non-progressing $k$-constant-cardinality path $\pi:[1,m] \rightarrow E^+$.

\item
$\kappa(n,k) = \kappa(1,n,k)$ is the same quantity in the case of multigraph 
with a unique vertex.
\end{enumerate}
\end{definition}

We already proved that $\kappa(g,n,k) \le g  \genfrac(){0pt}{1}{n}{k}-1$:
see Theorem 
\ref{theorem-finiteness-value-flow-2}.{theorem-finiteness-value-flow-2-1}.
When $g=1$ we deduce $\kappa(n,k) \le \genfrac(){0pt}{1}{n}{k}-1$. 

Our aim is to prove the following lower bound result
for one-vertex multigraph: $\kappa(n,k) \ge (n-k)k$, then
the following results for any multigraph: $\kappa(g,n,k) \ge g(n-k)k + (g-1)$
We will obtain in this way a more precise interval for the value $\kappa(n,k)$:

$$
\kappa(n,k) \ \in \ [ (n-k)k,  \ \genfrac(){0pt}{1}{n}{k}-1 ]
$$

For multigraphs with any number $g$ of vertices we will deduce the more general result:
$\kappa(g,n,k) \ \in \ [ g(n-k)k+(g-1),  \ g  \genfrac(){0pt}{1}{n}{k}-1 ]$.
Unfortunately, this is a wide iterval, with a polynomial lower bound and an exponential 
upper bound, this is all we know for the moment.

In order to provide the bound, we first define a
set $\setR \subseteq \setP(X^2)^2$ of pairs $(\Stat,\Prog)$ of relations on $X = [1,n]$
which satisfies PDC.

\begin{definition}[The set $\setR$ of bi-colored relations]
$\setR \subseteq \setP(X^2)^2$ is the set of all pairs $(\Stat,\Prog)$ 
of relations on $X$ such that:
\begin{enumerate}
\item
$R = \universe{(\Stat,\Prog)} = \Stat \cup \Prog$ is injective and surjective
with $\dom(R) \subset X$.

\item
The relation $\Stat$ is a weakly increasing partial function which is extending:
$\forall x,y \in X. x \Stat y \implies x \le y$. 

\item
if there is some progress from $x$, then the map $\Stat$ is strictly extending from $x \in X$.
Namely: $\forall x,y,z \in X$, if $x \Stat y$ and $x \Prog z$ then $x < y$.
\end{enumerate}
\end{definition}

We check that $\setR$ is composition-closed and satisfies PDC.

\label{lemma-composition-closed}

\item

\item

\begin{proof}

\universe{(\Stat,\Prog)} \universe{(\Stat',\Prog')}$. We check all clauses
of the definition of $(\Stat'',\Prog'')  \in \setR$.
 
\begin{enumerate}
\item
$R$ is injective and surjective, being the composition of two relations which are injective and surjective. We have $\dom(R) \not = X$, because 
$\dom(R) \subseteq \dom(\universe{(\Stat,\Prog)} \subset X$.

\item
$\Stat'' = \Stat\Stat'$ is an extending weakly increasing partial function, being the
composition of two extending weakly increasing partial functions. 

\item
Assume $x,y,z \in X$, $x \Stat'' y$ and $x \Prog'' z$ in order to prove that $x < y$. 
From $x \Stat'' y$ we deduce $x \Stat t \Stat' y$ for some $t \in X$, with $x \le t \le y$. 
If $x  < t$ then $x < y$. Assume $x = t$ instead:
then for no $u \in X$ we have $x \Prog u$. 
From $x \Prog'' z$ we deduce that for some $u \in X$ we have $x R u R z$, where one of the
two relations is a progress. From $\neg (x \Prog u)$ we deduce that $u \Prog' z$. From

\end{enumerate}

\item

if $t \Stat u$ then $u \ge z > x$ because $\Stat$ is weakly increasing. We deduce that
$x \not \in \codom(\Stat)$, and from $x \in \codom(R)$ we conclude that
there is some $v \in \dom(R)$ such that $v \Prog x$. This is PDC.

\end{enumerate}
\end{proof}

\subsection{GTC, SCT-a are equivalent to PDC in the case of injectivity}(Previous proof, only
included for record)
\label{subsection-SCT-PDC}

The implication GTC $\Rightarrow$ PDC follows from the fact that
for all self-composable $\composable{\setG}{a}{a}{(\Stat,\Prog)}$ 
there is some path $\pi = a,a,a,a,\ldots$ labeled $R,R,R,R,...$,
where $R = \universe{(\Stat,\Prog)} = \Stat \cup \Prog$. By GTC,
there is some infinitely progressing trace $z_1,z_2,z_3,\ldots$ in $\pi$.  
In any progressing point $i$ of the trace we have $z_i \Prog z_{i+1}$
and $z_{i+1} R z_{i+2}$. We conclude that $z_i \Prog z_{i+1}$
and $z_i, z_{i+1} \in \dom(R)$ for some $z_i, z_{i+1}$, that is,
PDC for the self-composable pair $(\Stat,\Prog)$.
\\

In order to prove $\SCTa$ $\Rightarrow$ PDC, we recall 
that Neil Jones in \cite{Lee1} 
proved the equivalence of the conditions called in this paper 
$\SCTa$ (\S \ref{section-SCT}) and GTC
$$
\forall \setR, \setG.  \ \ 
(\SCTa \Leftrightarrow GTC)
$$
Thus, from GTC $\Rightarrow$ PDC just proved we deduce $\SCTa \Rightarrow$ PDC. 
We proved one direction, namely point \label{property-2} of the Claim.
\\

Now we prove the other direction, namely point \label{property-1} of the Claim.
It is enough to prove that if $\setR$ is injective then PDC $\Rightarrow \SCTa$. If will follow
if $\setR$ is injective then PDC $\Rightarrow$ GTC. 

We first prove a property of injective transitive relation: this property does not
involve coloring, nor the fact that the relation is finite.

\begin{proposition}[Transitive Injective Relations]
\label{proposition-transitive-injective}
Assume $X$ is any set and $R \subseteq X \times X$ is any binary relation.
\begin{enumerate}
\item
\label{proposition-transitive-injective-01}
If $R$ is transitive and $R$ is injective, then any two elements of $\dom(R)$ related by $R$ 
are equal, namely $R \restr \dom(R) \subseteq \id_{\dom(R)}$.
\item
\label{proposition-transitive-injective-02}
If $R=RR$ and $R$ is injective, then two elements of $\dom(R)$ are related by $R$ 
\emph{if and only if} they are equal, namely $R \restr \dom(R) = \id_{\dom(R)}$.
\end{enumerate}
\end{proposition} 

\begin{proof}
\begin{enumerate}
\item
%\label{proposition-transitive-injective-01}
Assume $x, y \in \dom(R)$ and $x R y$ in order to prove $x = y$. 
From $y \in \dom(R)$ we deduce that for some
$z \in X$ we have $y R z$. By transitivity of $R$ we have $x R z$. By $y R z$ and injectivity
we conclude that $x = y$, as wished.

\item
%\label{proposition-transitive-injective-02}
Assume $x, y \in \dom(R)$ in order to prove $x = y$ if and only if $x R y$. By $R=RR$
we deduce that $R$ is transitive, and by point \ref{proposition-transitive-injective-01} above,
that $x R y$ implies $x=y$. Now we assume $x=y$ in order to prove $x R y$. 
From $x \in \dom(R)$ we deduce $x R z$ for some $z \in X$. From $R =RR$ we deduce
that for some $v \in X$ we have $x R v$ and $v R z$. From $x R z$, $v R z$ and injectivity
we obtain $x = v$. From $x R v$ and $x = y$ we conclude that $x R y$,
as wished.
\end{enumerate}
\end{proof}

We now prove that all \emph{finite} relations have some positive power which is idempotent:
this is a particular case of the fact that all elements of a finite monoid 
have some positive power which is idempotent (Prop. \ref{proposition-idempotent-power}).

\begin{proposition}
\label{proposition-idempotent-power}
Assume $X$ is any finite set and $R \subseteq X \times X$ is any finite binary relation.
Then for some $n>0$ we have $R^n=R^nR^n$.
\end{proposition}

\begin{proof}
Since $R$ is finite, there are only finitely many powers of $R$, therefore 
for some $a,b>0$ we have $R^a = R^{a+b}$. Then for all $c \ge a$ we have $R^c = R^{c+b}$,
hence $R^c = R^{c+db}$ for all $d>0$. Take the first $d>0$ such that $db \ge a$: then 
$R^{db} = R^{db+db}$. We take $n=db$.\footnote{There is an alternative proof using
Finite Ramsey Theorem. We take the complete graph on $\N$, and we color the 
edge between $i$ and any $j>i$ with $R^{j-i}$. There are finitely many colors.
By Finite Ramsey Theorem there is a monocromatic set with $3$ elements $i<j<k$. 
If the color of the set is $R^m$, then the edge between $i$ and $j$ and between $j$ and $k$
is $R^m$. By definition of coloring, the edge between $i$ and $k$ is $R^mR^m$, 
by Ramsey Theorem it is $R^m$. We conclude that $R^m = R^mR^m$. }
\end{proof}

We can now prove that if we have injectivity then PDC $\Rightarrow \SCTa$.

\begin{theorem}
Assume $X$ is any finite set and $\setR \subseteq X \times X$ is any composition-closed
finite family of finite bi-colored \emph{injective} binary relations. If $\setR$ satisfies PDC and 
is \emph{injective} then $\setR$ satisfies $\SCTa$.
\end{theorem}


\begin{proof}
Assume that $(S,P) \in \setR$ is some bi-colored finite relation on $X$,
in order to prove Finite Power Condition FPC (Def. \ref{definition-FPC}): namely, 
that for some $n \in \N$, $n>0$, for $(S_n,P_n) = (S,P)^n$ there is some
$x \in X$ such that $x P_n x$. By Prop. \ref{proposition-SCT}, we will conclude $\SCTa$.

Let $R = \universe{(S,P)} = S \cup P$. $R$ is finite, therefore by Prop. 
\ref{proposition-idempotent-power} for some $n \in \N$ we have $R^n = R^nR^n$. 
In particular, $R^n$ is transitive. 
We have $R^n = \universe{(S,P)}^n = \universe{(S,P)^n}$. By composition-closure of 
$\setR$ we deduce  $(S,P)^n \in \setR$, hence $R^n$ is injective and $(S,P)^n$ satisfies PDC. 
Thus, there are $x, y \in \dom(\universe{(S,P)^n}) = \dom(R^n)$ such that $x P_n y$, 
hence $x R^n y$. By proposition 
\ref{proposition-transitive-injective}.\ref{proposition-transitive-injective-01} 
we obtain that $x = y$. We conclude that $x P_n x$, as wished.
\end{proof}


\subsection{GTC, SCT-a, PDC  are equivalent in the case of injectivity: 
yet another proof proof}
(proof included for record)
\label{subsection-SCT-PDC-old}
We first provided an alternative proof that 
the \emph{injective self-composable idempotent relations $R$} are the identity relation when 
restricted to $\dom(R)$. This proof only works in the case of \emph{finite} relations,
so it is weaker than 
\ref{proposition-transitive-injective}.\ref{proposition-transitive-injective-02}.

As a corollary we will deduce that (PDC $\Rightarrow$ $\SCTa$), in an alternative way.

$R$ is a finite relation on a finite set $X$, therefore by Prop. 
\ref{proposition-idempotent-power} for some $m>0$ we have $R^m=R^mR^m$. 
If $R$ is injective, then $R^m$ is also the identity on $\dom(R^m)$.


\begin{proposition}[Idempotent Injective Relations
and the Global Trace Condition]
\label{proposition-idempotent-relations}
Assume $\setG$ is a multi-graph, $(\Stat,\Prog) \in \setR^\setG$ is self-composable, 
$R = \universe{(\Stat,\Prog)}$ is an \emph{injective} relation on a finite set $X$ and $RR=R$. 
Then:
\begin{enumerate}

\item
$R \restr \dom(R) $ is a bijection

\item
$R \restr \dom(R) $ is the identity and all
$x \in \dom(R)$ are weakly or strongly progressing to themselves.

\item
PDC $\Rightarrow$ $\SCTa$.
\end{enumerate}
\end{proposition}

\begin{proof}
\begin{enumerate}
\item
We have to prove that \emph{$R \restr \dom(R) $ is a bijection}. 
Let $\dom(R) = \{y_1, \ldots, y_m\}$. Assume
$i \in [1,m]$, $y_i \in \dom(R)$: 
from $R=RR$ we deduce that $y_i \in \dom(RR)$, therefore
there are $(y_i,y) \in R$ and $(y,z) \in R$. From $(y,z) \in R$ 
we obtain $y \in \dom(R)$. 
Let $C_i = \{y \in \dom(R) |(y_i,y) \in R\}$ and $c_i = \Card(C_i)$. 
By $y_i \in \dom(R)$ 
we have $c_i \ge 1$, hence $\Sigma_{i \in [1,m]} c_i \ge m$. 
By injectivity of $R$ if  $C_i \cap C_j \not = \emptyset$ then $i=j$, therefore 
$\{C_i | i \in [1,m]\}$ are a partition of some subset of $\dom(R)$
and we have $\Sigma_{i \in [1,m]} c_i \le m$. 
We deduce that $\Sigma_{i \in [1,m]} c_i  = m$,
and from it that $c_i=1$ for all $i \in [1,m]$. Thus, 
$R \restr \dom(R) $ is an injection on a finite set $\dom(R)$.
By the characterization of bijections on finite sets we 
conclude that $R \restr \dom(R) $ is a bijection.

\item
In the point above we proved that $R \restr \dom(R) $ is 
a bijection and we have to prove that \emph{it is an identity}. Any bijection
of the finite set $\dom(R)$ is an union of pairwise disjoint cycles of the form 
$D = \{z_1, \ldots, z_p\}$ for some $p \ge 1$. We have $z_i R z_j$
if and only if $j = i+1 \mod p$ and we have
$z_i RR z_j$ if and only if $j = i+2 \mod p$.
From $R=RR$ and $z_1 R z_2$ we deduce $z_1 RR z_2$, then by choosing
$i=1$, $j=2$ that $2=1+2 \mod p$, and eventually that $0=1 \mod p$. 
We conclude that $p=1$. Thus, all cycles in
$R \restr \dom(R) $ are unary and therefore
$R \restr \dom(R) $ is the identity.

We prove that \emph{for all $x \in \dom(R)$, $x$ is progressing or 
weakly progressing to itself}.
From $R \restr \dom(R)$ identity (the previous point)
we deduce that $x R x$, either $x$ is progressing to $x$ or 
$x$ is weakly progressing to $x$.

\item
We assume PDC and that $R = \universe{(\Stat,\Prog)}$ and $(\Stat,\Prog) (\Stat,\Prog) = 
(\Stat,\Prog)$, hence $R=RR$, 
in order to prove that \emph{for some $x \in X$, $x$ is progressing to itself}.
By PDC there are some $x,y \in \dom(R)$ such that $x$ is progressing to $y$.
By the previous point $R \restr \dom(R) $ is an identity.
We deduce that $x=y$. Thus, some $x \in \dom(R) \subseteq X$ is progressing to itself.

\end{enumerate}
\end{proof}


\subsection{Global Trace Condition (GTC) is equivalent toTermination of Computations (TC)}
\label{subsection-TC}
In this section we prove that the Global Trace Condition is equivalent to
the \emph{termination of all computation flows}, from now on, just TC for short.

We recall that a computation flow is some sequence 
$((a_1,(\Stat_1,\Prog_1),a_2),\sigma_1)$,
$((a_2,(\Stat_2,\Prog_2),a_3),\sigma_2), \ \ldots$ of states, such that
$$\composable{\setG}{a_1}{a_2}{(\Stat_1,\Prog_1)}, \ \ \ 
\composable{\setG}{a_2}{a_3}{(\Stat_2,\Prog_2)}, \ldots$$ and
for all $x, y \in X$, whenever $x \Stat_i y$ then $\sigma_i(x) \ge \sigma_{i+1}(y)$,
whenever $x \Prog_i y$ then $\sigma_i(x) > \sigma_{i+1}(y)$.

\begin{definition}[TC]
TC is short for: all possible computation flows terminate.
\end{definition}

Using Classical Logic, 
it is immediate that GTC $\implies$ TC. Indeed, in any infinite computation 
flow there is some variable $x \in X$ with some infinitely progressig trace. 
This implies that the value of $x$ is infinitely decreasing in the domain $\N$,
and this cannot be. 


The converse TC $\implies$ GTC is true but not immediate. Using Classical 
Logic, we prove it in the form $\neg$ GTC $\implies$ $\neg$ TC. Actually
we prove a stronger result: if GTC is false, there is some \emph{constant}
infinite transition $s, s, s, \ldots$ for some $s = (\Stat,\Prog),\sigma) \in \setS$,
in particular Termination of Computations (TC) fails. In this infinite
transition all variables are constant, and all 
traces progress at most $n-1$ times, with $n=\Card(X)$.

\begin{proof}[Proof of $\neg$ GTC $\implies$ $\neg$ TC]
Assume $\neg$ GTC. By Theorem 4, \cite{Lee1} 
we deduce $\neg$ $\SCTa$, namely
that there is some self-composable 
$(a,(\Stat,\Prog),a) \in \setR$ such that for no $m \in \N$, $m>0$, 
$x \in X$ we have $x$ progressing to itself in $(\Stat,\Prog)^m$.

We first define: $s = ((\Stat,\Prog),\sigma) \in \setS$; then
some \emph{constant }infinite transition by: $\theta = (s, s, s, \ldots)$.

We say that a trace $\tau:[1,t] \rightarrow X$ 
is irredundant if and only if all its elements are 
pairwise distinct, namely: $\forall i,j \in [1,t]. \tau(i) = \tau(j) \implies i=j$. 
An irredundant trace has at most $n$ elements, where  $n = \Card(X)$, and
progresses at most $n-1$ times, because the last element of the trace
does not progress, having no next element.
\\

Let $\pi = (\Stat,\Prog), (\Stat,\Prog), \ldots$
be the infinite constant path repeating the self-composable pair $(\Stat,\Prog)$.
We set $\sigma(x)=$ the maximum number of progressions in
an irredundant trace $\tau$, starting
 from $x$ and compatible with $\pi$. The maximum
exists because an irredundant trace has at most $n$ elements,
therefore there are finitely many irredundant traces from $x$. In fact,
we also know that $\sigma(x) \le n-1$.
\\

Now we prove that $\theta = (s, s, s, \ldots)$ is a constant infinite transition.
We have to prove that for all $x,y \in X$ if $x \Stat y$ then $\sigma(x) \ge
\sigma(y)$ and if $x \Prog y$ then $\sigma(x) >
\sigma(y)$, namely $\sigma(x) \ge \sigma(y)+1$. 
Assume $\sigma(x) = a$ and $\sigma(y) = b$.  
By definition of $\sigma$ there is some irredundant trace $\tau$ from $y$ 
whose progressing points in $\pi$ are in number of $b$. 
We have to prove that $\sigma$ is compatible with $(\Stat,\Prog)$,
namely that $a \ge b$ if $x \Stat y$ and $a \ge b+1$ if $x \Prog y$.
\\

For, we define a trace $\rho = (x) \conc \tau$.
$\rho$ could be not irredundant, however we can repeatedly replace each
cycle included in $\rho$ with its first element. 
Each time we obtain a shorter trace from $x$, eventually we obtain an irredundant
trace $\rho'$. All the cycles we removed are not progressing,
otherwise there would be some power of $(\Stat,\Prog)$ and some $z \in X$
 progressing to itself. Therefore whenever we remove a cycle from$\rho$
 we preserve the number of progressions. This number is $b$ if $x \Stat y$
 and is $b+1$ if $x \Prog y$. By definition of $\sigma(x) = a$ we deduce
 $a \ge b$ if $x \Stat y$ and $a \ge b+1$ if $x \Prog y$, as wished.
\end{proof}

Remark that in fact we proved a stronger property: either we have $\SCTa$ and
GTC and TC, or we have $\neg$ $\SCTa$ and $\neg$ GTC and $\neg$ TC. In the
second case we also have an infinite constant transition $\theta = (s, s, s, \ldots)$
with $s = ((\Stat,\Prog),\sigma) \in \setS$, in which each variable $x \in X$ has constant
value $\sigma(x)$, and all traces progresses at most $n-1$ times, where $n=\Card(X)$.

\item

The translated inductive proof is correct. 
\end{theorem}

\begin{proof}

Suppose we have nested induction on 
$(\size(D_1),h_1,\size(D_2),h_2, \ldots, \size(D_k),h_k)$. We prove 
that the translated inductive proof is correct. 

\begin{enumerate}
\item
Suppose $D_k \subseteq \dom(S)$. Then $\Card(S(D_k)) \ge \Card(D_k)$.
Suppose  that $\Card(S(D_k)) > \Card(D_k)$.
Then all $D_1, \ldots, D_k$ stay the same and we add a new set $D_{k+1} = S(D_k)$. 
Then the translated proof is correct because when we add a new element the sequence
is smaller.

\item
Suppose $D_k \subseteq \dom(S)$ and $\Card(S(D_k)) = \Card(D_k)$.
Then all $D_1, \ldots, D_{k-1}$ stay the same and $S$ is a bijection 
from $D_k$ to $X'_k=S(D_k)$. Then $\size(D_k) \ge \size(X'_k)$.
Suppose $S$ is a \emph{stationary} bijection. Then $\height(D_k,c) > \height(X'_k,d)$
and the translated proof is correct.

\item
Suppose  $S$ is a \emph{progressing} bijection. Then $\size(D_k) \ge \size(X'_k)$ 
and the translated proof is correct.

\item
Suppose $D_k \not \subseteq \dom(S)$. Then there is a first $i \in [1,k]$ such that the new value 
of $D_i$ is some $Y \subset D_i$ and $D_i$ is associated to some $c$.

then $Y$ is the new value of $D_{i-1}$ and $\size(D_i) > \size(Y)$. 
Then the translated proof is correct.
Otherwise we have $i>1$ and  $\Card(D_{i-1}) =  \Card(Y)$. In this case
$Y$ is the new value of $D_{i-1}$, not of $D_i$, which instead disappears.
Then $\height(D_{i-1},c) > \height(Y,d)$ and the translated proof is correct.
\end{enumerate}
\end{proof}

\section{A New Classical proof of (Injectivity + PDC) $\implies$ GTC}
\label{section-classical-proof-PDC-implies-GTC}
\emph{Proof started in Torino, December 23, 2025}. 
\\

\newcommand{\MaxInd}{{\tt M}}

We consider finite binary relations whose pairs have two colors.
Colors are given by decomposing a finite 
relation in the disjoint union of two sets $\Stat$ and $\Prog$: the color we assign to 
a pair depends on the subset the pair belongs to.

\begin{definition}[Bicolored  Relation on a finite set]
\label{definition-bicolored-relation}
Let $\MaxInd \in \N^+$ be any positive integer. 
 \begin{enumerate}
\item
A bicolored relation on the set $\{1, \ldots, \MaxInd\}$ is any pair
$R = (\Stat,\Prog)$ of \emph{disjoint} binary relations on $\{1, \ldots, \MaxInd\}$. 
\item
When $(x,y) \in \Stat$ we say that $(x,y)$ has the \emph{stationary} color in $R$, 
and when $(x,y) \in \Prog$ we say that $(x,y)$ has the \emph{progressing} color in $R$.
\item
If $R = (\Stat,\Prog)$ we call the binary relation $\universe{R} = \Stat \cup \Prog$ 
\quotationMarks{the uncolored version of $R$}. 
\end{enumerate}
\end{definition}

The assumption $\Stat \cap \Prog =\emptyset$ means that no pair $(x,y)$ has both colors in 
$R$.  $\universe{R}$ is the plain binary relation obtained by stripping off colors from $R$. 
We now define a notion of composition for bi-colored relations.

\begin{definition}[Composition of bicolored  relations]
\label{definition-composition}
Let $\setR$ be any set of bicolored relations on $\{1, \ldots, \MaxInd\}$ and 
$(\Stat,\Prog), (\Stat',\Prog') \in \setR$.
 \begin{enumerate}
\item
$(\Stat,\Prog) \comp (\Stat',\Prog') = (\Stat'',\Prog'')$,
with $\Prog''=\Stat\Prog' \cup \Prog\Stat'\cup \Prog\Prog'$ 
and $\Stat'' = \Stat\Stat'\setminus \Prog''$.
\item
$\setR^+$ is the closure of $\setR$ under composition.
\end{enumerate}
\end{definition}

The families $\setR$ and $\setR^+$  have at most $2^{\MaxInd*\MaxInd}$ 
elements, hence they are finite. 
Assume $R$, $S$ are bicolored relations on $\{1, \ldots, \MaxInd\}$. 
This is the unfolding in words of the definition \ref{definition-composition}
of composition for $RS$. Assume $x, y \in \{1, \ldots, \MaxInd\}$:

\begin{enumerate}
\item
if for some $y\in \{1, \ldots, \MaxInd\}$ we have $(x,y) \in \universe{R}$ and $(y,z) \in \universe{S}$ and either 
$(x,y)$ is progressing in $R$ or $(y,z)$ is progressing in $S$, then  
$(x,z)$ is progressing in $RS$. 

\item
if \emph{the previous condition is false}, and for some $y$ we have
$(x,y) \in \universe{R}$ and $(y,z) \in \universe{S}$  and $(x,y)$ is stationary
in $R$ and $(y,z)$ is stationary in $S$, then  $(x,z)$ is stationary in $RS$. 
\end{enumerate}

Remark that $\Stat''$ and $\Prog''$ in the definition
 $(\Stat'',\Prog'') = (\Stat,\Prog) \comp (\Stat',\Prog')$ are disjoint 
because we defined $\Stat'' = \Stat\Stat' \setminus \Prog''$. 
Unstripping colors commutes with composition of colored relations:

\begin{lemma}[Composition Lemma]
\label{lemma-composition}
Assume $R=(\Stat,\Prog)$, $R’=(\Stat',\Prog')$ are two pairs of disjoint relations on 
$\{1, \ldots, \MaxInd\}$. Then $\universe{RR’} = \universe{R}\universe{R'}$.
\end{lemma}

\begin{proof}
By definition unfolding we have 
\begin{enumerate}
\item
$
\universe{RR’} = 
\Stat'' \cup \Prog'' = 
(\Stat\Stat'\setminus \Prog'') \cup \Prog'' = 
\Stat\Stat'\cup \Prog'' = 
\Stat\Stat'\cup \Stat\Prog' \cup \Prog\Stat'\cup \Prog'\Prog''$

\item
$
\universe{R}\universe{R'} = 
(\Stat \cup \Prog)(\Stat'\cup \Prog') = 
\Stat\Stat'\cup \Stat\Prog' \cup \Prog\Stat'\cup \Prog\Prog'
$
\end{enumerate}
We conclude that $\universe{RR’} = \universe{R}\universe{R'}$
\end{proof}

We suppose having a finite direct multigraph $\setG$ whose edges are labeled with relation of $\setR$. Namely, $\setG$ is any finite set of triples $(a,R,b)$ with $R \in \setR$, $a,b \in \N$,
and $a,b$ are called the nodes of $\setG$. We write $R:a \rightarrow b$ for: $(a,R,b) \in \setG$. 
Assume $I=[0,k]$ for some $k \in \N$ or $I=\N$.
We call a path $\pi$  in $\setG$ any sequence of labeled 
edges $\pi: I \rightarrow \setG$, such that $\pi(i)=(a_i,R_i,a_{i+1})$ for all $i \in I$: the
ending node of $\pi(i)$ is the starting node of $\pi(i+1)$, if $i+1 \in I$. If $I=[0,k]$, 
we call $R_0 \ldots R_k: a_0 \rightarrow a_{k+1}$ the composition of $\pi$. 
We call $\setG^+$ the set of compositions of paths of $\setG$. The nodes of $\setG^+$ are the nodes of $\setG$ and $\setG^+$ is labeled by bicolored relations in $\setR^+$.
\\

Assume $\pi: I \rightarrow \setR$ is a path, with  $I=[0,k]$ for some $k \in \N$ or $I=\N$.
Assume $\pi(i)=(a_i,R_i,a_{i+1})$ for all $i \in I$. A trace associated to $\pi$
is any sequence $\sigma : J \rightarrow \{1, \ldots, \MaxInd\}$, with $J=[0,k+1]$ or $J=\N$ according
if $I=[0,k]$ or $I=\N$,
and such that $\sigma(i) \universe{R_i} \sigma(i+1)$ for all $i \in I$. 
\\

If $\pi = \{ R_i = (\Stat_i,\Prog_i):a_i \rightarrow a_{i+1} | i \in \N\} $ is any infinite path, for all $0 \le i \le j$ we define $D_{i,j} = \dom(R_i \ldots R_j)$ and $D_{i} = \cap_{j \ge i} D_{I,j}$. $D_i$ is the set of $x \in \{1, \ldots, \MaxInd\}$ such that for all integer $j \ge i$ there is some trace associated to the restriction of $\pi$ to $[i,j]$ and starting from $x$. $D_{i,j}$ is a weakly decreasing sequence in the index $j$ because $\dom(R_i \ldots R_j) \supseteq \dom(R_i \ldots R_{j+1})$. Each $D_{i,j}$ has at most $\MaxInd$ elements, therefore $D_{i,j}$  can decrease at most $\MaxInd$ times. Thus, for some $j \ge i$ and all $k \ge j$ we have $D_{i,j} = D_{i,k}$, hence $D_i = D_{i,j} = D_{i,k}$. Conversely, if $D_i = D_{i,j}$ then for all $k \ge j$ we have $D_i = D_{i,k}$. We define $\phi(i) = $ the first $j$ such that $D_i = D_{i,j}$.
\\

\begin{definition}[Progressing trace]
\label{definition-progressing-trace}
Assume $\sigma$ is a trace associated to a path $\pi = \{ R_i = (\Stat_i,\Prog_i):a_i \rightarrow a_{i+1} | i \in I\} $.
\begin{enumerate}
\item
$\sigma$ is progressing in the step $i$ if and only if  $i, i+1 \in I$ and $\sigma(i) \Prog_i \sigma(i+1)$. \item
$\sigma$ is infinitely progressing if and only if $\sigma$ is progressing in infinitely many steps.  
\end{enumerate}
\end{definition}

The Global Trace Condition (GTC) says: 

\begin{center}
\emph{any infinite path on $\setG$ has some tail associated to some infinitely progressing trace}. 
\end{center}

It is know that GTC is equivalent to: \emph{for all $R = (\Stat,\Prog) : a \rightarrow a \in \setR^+$, if $R=RR$ then there is some $x \in \{1, \ldots, \MaxInd\}$ which is progressing to itself: $x \Prog x$}. We want to find a simpler condition equivalent to GTC in a particular case.

\begin{definition}[The Progressing Domain Condition (PDC)]
\label{definition-Progressing-Domain-Condition-PDC}
Assume that $R = (\Stat,\Prog) : a \rightarrow a$ is a bicolored binary relation on 
$\{1, \ldots,\MaxInd\}$ and $\setR$ is a finite set of such relations.
\begin{enumerate}
\item
We say that $R$ satisfies PDC if and only if $x \Prog y$ for some 
$x, y \in \dom(\universe{R})$.
\item
We say that $\setR$ satisfies PDC if and only all $R \in \setR$ satisfy PDC
\end{enumerate}
\end{definition}

PDC for  $R=(\Stat,\Prog)$ implies that $\Prog \not = \emptyset$ and therefore $\universe{R} \not = \emptyset $ are not empty. It says a little more, namely that there is some connection $x R y$ starting and ending in $\dom(R)$. We only consider injective relations.
\\

\begin{definition}
\label{definition-injectivity-condition-IC}
\emph{The injectivity condition for $\setR$} (IC) says: 
\quotationMarks{$\universe{R}$ is injective for all $R \in \setR$} . 
\end{definition}

Our goal is to prove that:

\begin{center}
IC for $\setR$ $\implies$ 
(GTC for $\setR^+$ $\Leftrightarrow$ PDC  for $\setR^+$)
\end{center}

The implication GTC $\implies$ PDC is immediate and it does not require the 
additional assumption IC.

\begin{lemma}
GTC for $\setR^+$ $\implies$  PDC for $\setR^+$
\end{lemma}

\begin{proof}
Assume $R:a \rightarrow a \in \setR^+$. We take the infinite path $\pi = R:a \rightarrow a, R:a \rightarrow a, R:a \rightarrow a,\ldots$ always repeating $R$ and cycling around $a$. By GTC some tail of $\pi$ has some infinitely progressing trace $\sigma$. Then $\sigma$ is progressing in some step $i$. Therefore $\sigma(i) \Prog \sigma(i+1)$ and $\sigma(i) \in \dom(\universe{R})$, $\sigma(i+1) \in \dom(\universe{R})$ by definition of trace. Thus, $\universe{R}$ is progressing in some $x, y \in \dom(\universe{R})$. 
\end{proof}

\begin{lemma}[Composition and Injectivity]
\label{lemma-composition-injectivity}
Assume $R=(\Stat,\Prog)$, $R’=(\Stat',\Prog')$ are bicolored relations on $\{1, \ldots, \MaxInd\}$
satisfying IC, and $RR’ = (\Stat'',\Prog'')$. 
Assume $\setR$ is a family of bicolored relations on $\{1, \ldots, \MaxInd\}$. 
\begin{enumerate}
\item
\label{lemma-composition-injectivity-01}
$RR’$ satisfies IC 

\item
\label{lemma-composition-injectivity-02}
If $\setR$ satisfies IC, 
then $\setR^+$ satisfies IC.

\item
\label{lemma-composition-injectivity-03}
$\Stat\Stat' \cap \Prog'' = \emptyset$

\item
\label{lemma-composition-injectivity-04}
$
(\Stat,\Prog) \comp (\Stat',\Prog') 
= 
(\Stat\Stat', \Stat\Prog' \cup \Prog\Stat'\cup \Prog\Prog')
$
\end{enumerate}
\end{lemma}

\begin{proof}
\begin{enumerate}

\item
%\label{lemma-composition-injectivity-01}
We assume that $\universe{R}$ and $\universe{R'}$ are injective
and we have to prove that $\universe{RR'}$ is injective.
By Lemma \ref{lemma-composition} we have $\universe{RR’} = \universe{R} \universe{R'}$. 
Then $\universe{RR’}$ is injective 
because the composition of two injective relations is injective.

\item
\label{lemma-composition-injectivity-02}
We assume that $\setR$ is a family of bicolored relations satisfying IC, 
and we prove that the closure by composition $\setR^+$ of $\setR$
satisfies IC.
This follow from the fact that IC 
is closed by composition (point \ref{lemma-composition-injectivity-01} above).

\item
\label{lemma-composition-injectivity-03}
We have to prove that $\Stat\Stat' \cap \Prog'' = \emptyset$.
We assume that $x \Stat\Stat' y$ and $x \Prog'' y$ in order to derive a contradiction. 
From $x \Stat\Stat' y$ we deduce that for some $z$ we have 
$x \Stat z \Stat' y$. From $x \Prog'' y$ we deduce that for some $t$ we have 
either $x \Stat t \Prog' y$ or $x \Prog t \Stat' y$ or $x \Prog t \Prog' y$. 
We consider the three sub-cases separately.
\begin{enumerate}
\item
\emph{Assume $x \Stat t \Prog' y$}.
Then we have $z \Stat' y$ and $t \Prog' y$. By injectivity of 
$\universe{R'} = \Stat'\cup \Prog'$ we deduce that $z = t$, then that 
$(z,y) \in \Stat'\cap \Prog'$, contradiction. 
\item
\emph{Assume $x \Prog t \Stat' y$}. Then we have $z \Stat' y$ and $t \Stat' y$.
By injectivity of $\universe{R'} = \Stat' \cup \Prog'$ we deduce again that $z = t$. 
From $x \Stat z$ and $x \Prog t$ and $z=t$ we conclude that 
$(x,t) \in \Stat \cap \Prog$, contradiction.
\item
\emph{Assume $x \Prog t \Prog' y$}. 
Then we have $z \Stat' y$ and $t \Prog' y$. By injectivity of 
$\universe{R'} = \Stat'\cup \Prog'$ we deduce again that $z = t$, then that 
$(z,y) \in \Stat'\cap \Prog'$, contradiction. 
\end{enumerate}

\item
\label{lemma-composition-injectivity-04}
From $\Stat\Stat'\cap \Prog'' = \emptyset$ and the definition
$\Prog'' =  \Prog\Stat'\cup \Prog\Prog'$ we deduce that 
$$
R \comp R’
= 
(\Stat\Stat'\setminus \Prog'', \Prog'')
= 
(\Stat\Stat', \Prog'')
=
(\Stat\Stat',   \Stat\Prog' \cup \Prog\Stat'\cup \Prog\Prog' )
$$ 

\end{enumerate}
\end{proof}

The next step is to provide a sufficient condition for the restriction of a bicolored relation
to be a bijection.

\begin{lemma}[Bijection Lemma]
\label{lemma-bijection}
\begin{enumerate}
\item
Assume $R$ is a bicolored relation on $\{1, \ldots, \MaxInd\}$
with IC.  
\item
Assume $X \subseteq \{1, \ldots, \MaxInd\}$
and $\universe{R} \cap (X \times X)$ is everywhere defined.
\end{enumerate}
Then $\universe{R} \cap (X \times X)$ is a bijection. 
\end{lemma}

\begin{proof}
Assume that $x \in X$ has $n_x$ images in $X$. By the assumption that $\universe{R} \cap (X \times X)$ is everywhere defined we have $n_x \ge 1$, therefore 
$\Card(X) \le \Sigma_{x \in X} n_x$. 
The $\universe{R}$-images of two different $x,y \in X$ are disjoint by injectivity, therefore $ \Sigma_{x \in X} n_x$ is the cardinality of the set of $\universe{R}$-images of $X$ in $X$, in particular we have $\Sigma_{x \in X} n_x \le \Card(X)$. 
We deduce that $\Sigma_{x \in X} n_x = \Card(X)$ and $n_x=1$ for all $x \in X$. 
\begin{enumerate}
\item
From  $n_x=1$ for all $x \in X$ we deduce that the images of $\universe{R} \cap (X \times X)$ exist and they are unique: $\universe{R} \cap (X \times X)$ is a function.
\item
From $\Sigma_{x \in X} n_x = \Card(X)$ we deduce surjectivity of $\universe{R} \cap (X \times X)$.
\item
$\universe{R} \cap (X \times X)$ is injective because it is a subset of an injective relation $R$.
\end{enumerate}
We conclude that $\universe{R} \cap (X \times X)$ is a bijection.
\end{proof}

Now we provide a sufficient condition for having an infinitely progressing trace.

\begin{lemma}[Infinitely Progressing Trace]
\label{lemma-infinitely-progressing}
 Assume that:
\begin{enumerate}
\item
IC holds for $\setR$. 
\item 
PDC (the Progressing Domain Condition) holds for $\setR^+$. 
\item
$\pi = \{R_i = (\Stat_i,\Prog_i) : a_i \rightarrow a_{i+1} | i \in \N \}$ is an infinite path in $\setG^+$, and that for some $X$ and all $i \in \N$ we have $X = \dom(\universe{R_i}) = \dom(\universe{R_i R_{i+1}})$.
\end{enumerate}
Then $\pi$ is associated to some infinitely progressing path.
\end{lemma}

\begin{proof}
We first prove that all $R_i \cap (X \times X)$ are everywhere defined.
By assumption we have $X = \dom(\universe{R_i}) =  \dom(\universe{R_iR_{i+1}})$. By 
Lemma \ref{lemma-composition} we have $\universe{R_iR_{i+1}} = \universe{R_i} 
\universe{R_{i+1}}$. Thus, for all $x \in X$ we have 
$x \in  \universe{R_i} \universe{R_{i+1}}$, 
therefore there are $y$, $z$ such that $x R_i y R_{i+1} z$. Then $y \in 
\dom(\universe{R_{i+1}})$, then $y \in X$ by the assumption $X = \dom(\universe{R_{i+1}})
$. We proved that $R_i \cap (X \times X)$ is everywhere defined. 

Any infinite trace $\sigma$ associated to $\pi$ satisfies $\sigma(i) R_i \sigma(i+1)$
and therefore $\sigma(i) \in \dom(R_i) = X$. By Lemma \ref{lemma-bijection} all relations 
$\universe{R_i} \cap (X \times X)$ are bijections, therefore $\sigma(i+1)$ is the
unique $R_i$-image of $\sigma(i)$ in $X$. Let $c = \Card(X)$: 
there are $c$ infinite traces associated to $\pi$, each one having some 
$x \in \dom(\universe{R_0}) = X$ as starting point and uniquely determined by $x$ 
because all $\universe{R_i} \cap (X \times X)$ are bijections. By 
PDC for $\setR^+$, for all $i \in \N$ there are some $a,b \in \dom(\universe{R_i})=X$ such 
that $a \Prog_i b$. Thus, for each $i \in \N$ at least one of the $c$ traces is progressing
in the step $i$. 
We conclude that at least one infinite trace is infinitely progressing.
\end{proof}

Now we can prove the following:

\begin{theorem}[The Progressing Domain Condition Theorem]
\label{theorem-PDC}
Assume IC for $\setR$. Then
\begin{center}
PDC for $\setR^+$ $\implies$ GTC for $\setR^+$
\end{center}
\end{theorem}

\begin{proof}
Take any infinite path $\pi = \{R_i = (\Stat_i,\Prog_i) : a_i \rightarrow a_{i+1} | i \in \N\}$ 
in $\setG^+$. Define $D_i = \bigcap_{j \ge i} \dom(R_i \ldots R_j)$. 
There are at most $2^{\MaxInd}$ 
possible values for $D_i$, therefore there is some $X$ such that $X=D_i$ infinitely many 
times. We already proved that there is a first $j = \phi(i)$ such that $D_i = \dom(R_i \ldots R_k)
$ for all $k \ge j$.

We define a subsequence $\pi’$ of $\pi$: $i_0 =$ the first $i$ such that $X = D_i$, and $i_{k+1} =$ the first $i$ such that $X= D_i$ and $i  \ge \phi(i_k) + 1$. Define $S_k = R_{i_k} \ldots R_{i_{k+1}-1}$: then $\dom(S_k) = D_{i_k, i_{k+1}-1} = X$ by $i_{k+1} -1 \ge (\phi(i_k) + 1) – 1 = \phi(i_k)$. From $ i_{k+2}-1 > i_{k+1}-1$ we have $\dom(S_k S_{k+1}) = D_{i_k, i_{k+2}-1} = X$. 

All relations $S_k$ satisfy IC by closure of IC under composition (Lemma \ref{lemma-composition-injectivity}.\ref{lemma-composition-injectivity-02}). Besides, we assumed PDC for $\setR^+$. 
From $\dom(S_k S_{k+1}) = D_{i_k, i_{k+2}-1} = X = \dom(S_k)$ for all $k \in \N$, 
by Lemma \ref{lemma-infinitely-progressing} we conclude the existence of some infinitely progressing trace for $\pi’$, hence for $\pi$.
\end{proof}

\section{A Poly-exponential Translation from Injective Cyclic to Inductive Proofs}
\emph{Proof started in Torino, January 20, 2026. Ugo suggests adding complexity results}.

Mirai \cite{} provided a translation from from cyclic to inductive proofs. The proof builds
on an existing algorithm for generating ranking functions and 
requiring triple exponential time. A first improvement would be to switch to an equivalent
formulation of cyclic proofs with injective bicolored relation (i.e. fan-in free, with at most one
arrow entering in each node). In this case, the same algorithm provides a double exponential
time \cite{} and an inductive proof in output of size $O(2^{n \log(n)})$.
In this paper we further improve the translation to a single exponential (poly-exponential) time, 
by introducing a new algorithm. The price is having an inductive proof in output
of poly-exponential size, instead than an ouput of size $O(2^{n \log(n)})$.


\subsection{Quick Overview of the GTC and PDC Conditions}
Let us start from a cyclic proof $\Pi$ with set $\setR$ of bicolored relations on a set 
$[1,\MaxInd]$. $\MaxInd$ is the maximum number of inductive formula in the left-hand side 
of some sequent in $\Pi$. Each relation $R$ is associated to an arrow $a \rightarrow b$ 
between nodes of $\Pi$, and any two relations $R:a \rightarrow b$, $S:b \rightarrow c$
are said to be composable.
 
Assume $\setR^+$ is the closure of $\setR$ under composition. The Progressing Domain 
Condition (PDC) for a bicolored relation $R : a \rightarrow a$ says: 
there are $x, y \in \dom(R)$ such that $R$ is progressing on $(x,y)$.
We say that set $\setR$ of bicolored relations on $\Pi$
satisfies PDC if and only if all $R \in \setR$ with $R: a \rightarrow a$ satisfy PDC. 
Remark that the Global Trace Condition (GTC) is a property of $\setR$ as a whole, 
while PDC is a property of single relations $R \in \setR$, $R:a \rightarrow a$. 

We assume that:

\begin{enumerate}
\item  
$\setR$ is a set of injective relations, hence $\setR^+$ is a set of injective relations, too.
\item
$\setR^+$ satisfies PDC 
\end{enumerate}

PDC for injective relations is equivalent to GTC, in general GTC is a stronger condition
than PDC. 
\\

{\bf An example.} Let $R = (\{(1,1),(2,2)\},\{(2,1)\})$ with $R$ progressing
on $(2,1)$. Then $R$ satisfies PDC on the graph $\{(a,a)\}$, and $RR=R$, 
therefore  $\setR^+=\{R\}$ and $\setR^+$ satisfies PDC. However, the only traces any
infinite path are $(1,1,1,\ldots)$ and $(2,2,2,\ldots)$ and $(2,2,2,\ldots,1,1,1,\ldots)$. The
first two traces never progress, the third trace progresses once, on $(2,1)$. So $\setR^+$
does \emph{not} satisfy GTC. This is not in contradiction with what we said, because
$R$ is  \emph{not} injective.
\\

Suppose we have a path $\pi$ from a companion c to itself, moving back  through $c$
for $k \ge 1$ times: we have $c \rightarrow c \rightarrow \ldots \rightarrow c$, with $k$ arrows.
For any $i \in \{1, \ldots, k\}$, suppose the step $c \rightarrow c$ having number $i$
is associated to some bicolored relation $R_i : c \rightarrow c$, $R_i \in \setR^+$. 
The path $\pi$ itself is associated to the sequence $\vec{R} = R_1 \ldots R_k$ of such relations. 
For the translation, we have to associate a measure to each such sequence $\vec{R}$
which is decreasing by extension.

In order to do so, we first to derive some elementar properties of the sequences of uncolored injective relations on $[1,\MaxInd]$. This properties having nothing to do with colors and
with cyclic proofs.


\subsection{Domain-Stable Sequences and Grouping}
\begin{definition}[Grouping]
A grouping of a sequence $\vec{S} = S_1, \ldots, S_n$ of binary relations is defined by 
induction on $n$ as follows.
\begin{enumerate}
\item
If $n=0$, then $\vec{S}$ (empty) is the unique grouping of $\vec{S}$.
\item
Suppose $T_1, \ldots, T_m$ is any grouping of $\vec{S}$. 
Then $T_1, \ldots, T_{i-1}, (T_i\ldots T_m)$ is a grouping of 
$\vec{S}$, for all $i \in [i,m]$. 
\end{enumerate}
\end{definition}

To put otherwise, the grouping of $S_1, \ldots, S_n$ are all and only 
sequences of products of the form: 
$$
S_{a_1} \ldots S_{b_1}, \ \ \ 
S_{a_2} \ldots S_{b_2}, \ \ \ 
\ldots, \ \ \ 
S_{a_{h+1}} \ldots S_{b_{h+1}}
$$
for some increasing sequence 
$0 < b_1 < b_2 < i_3 < \ldots < b_h < b_{h+1} = n$, and with $a_0=1$, $a_{i+1} = b_i+1$ 
for all $i \in [1,h]$.

Some trivial examples. 
\begin{enumerate}
\item
We can have $h=0$, $b_1=n$ and the trivial grouping consisting of a single product  
$S_1 \ldots S_n$. 
\item
We can have $h=m$, $b_1=1$, \ldots, $b_m=n$ 
and the trivial grouping consisting of the sequence 
$S_1, \ldots, S_n$ itself, considered a sequence of unary products.
\end{enumerate}

We first define some domain inclusions and equalities 
which are valid for all sequences of relations.

\begin{lemma}[Domain-inclusion]
\label{lemma-domain-inclusion}
Assume $R, S, T$ are any relations and $R_1, \ldots, R_n$ is any sequence of relations.
\begin{enumerate}

\item
\label{lemma-domain-inclusion-01}
For any two relations $R$, $S$ we have $\dom(RS) \subseteq \dom(R)$.

\item
\label{lemma-domain-inclusion-02}

$$
\dom(R_1)   \ \ \  \supseteq  \ \ \ 
\dom(R_1 R_2)    \ \ \  \supseteq  \ \ \ 
\dom(R_1 R_2 R_3)    \ \ \  \supseteq  \ \ \  
\ldots   \ \ \  \supseteq
\dom(R_1 \ldots R_n)
$$

\item
\label{lemma-domain-inclusion-03}
$(\dom(R) = \dom(RS))  
\ \ \  \Leftrightarrow \ \ \ 
(\dom(R) \subseteq \dom(RS)) 
\ \ \  \Leftrightarrow \ \ \  
(\dom(R) \not \supset  \dom(RS))
$.

\item
\label{lemma-domain-inclusion-04}
If $\dom(S) = \dom(ST)$ then 
$\dom(RS) = \dom(RST)$.

\end{enumerate}
\end{lemma}

\begin{proof}
\begin{enumerate}

\item
%\label{lemma-domain-inclusion-01}
We have to prove that $\dom(RS) \subseteq \dom(R)$. For, we assume $x \in \dom(RS)$ in 
order to prove that $x \in \dom(R)$. If $x \in \dom(RS)$ then for some $z$ we have $x RS z$, 
therefore $x R y S z$ for some $y$. We conclude that $x \in \dom(R)$, as wished.

\item
%\label{lemma-domain-inclusion-02}
We prove 
$
\dom(R_1) \supseteq 
\dom(R_1 R_2) \supseteq 
\dom(R_1 R_2 R_3) \supseteq 
\ldots \supseteq 
\dom(R_1 \ldots R_n)
$ 
by induction on $n$. 
When $n=0,1$ there is no inclusion to prove. Suppose $n \ge 1$ and the thesis 
for $n$, namely that $\dom(R_1) \supseteq \dom(R_1 R_2) \supseteq \dom(R_1 R_2 R_3) 
\supseteq \ldots \supseteq \dom(R_1 \ldots R_n)$. We have to prove the thesis for $n+1$. 
By point \ref{lemma-domain-inclusion-01}above 
we have $\dom(R_1 \ldots R_{n} R_{n+1}) \subseteq \dom(R_1 \ldots R_{n})$, namely. 
$\dom(R_1 \ldots R_{n}) \supseteq \dom(R_1 \ldots R_{n} R_{n+1})$. 
From this and the inductive hypothesis we deduce the thesis for $n+1$.

\item
%\label{lemma-domain-inclusion-03}
If $(\dom(R) = \dom(RS))$ then $(\dom(R) \subseteq \dom(RS))$. If
$(\dom(R) \subseteq \dom(RS))$, then $(\dom(R) \not \supset \dom(RS))$.
If $(\dom(R) \not \supset \dom(RS))$, then from $(\dom(R) \supseteq \dom(RS))$
(point \ref{lemma-domain-inclusion-01}above) we deduce that $(\dom(R) = \dom(RS))$.

\item
%\label{lemma-domain-inclusion-04}
Assume that $\dom(S) = \dom(ST)$ in order to prove that 
$\dom(RS) = \dom(RST)$. 
We have $\dom(RS) \supseteq \dom(RST)$ by point \ref{lemma-domain-inclusion-01} above,
so we only have to prove that $\dom(RS) \subseteq \dom(RST)$.
For, we assume $a \in \dom(RS)$ in order to prove that $a \in \dom(RST)$. 
From $a \in \dom(RS)$ we deduce that there are $b \in \dom(S)$ and $c$ such that $a R b S c$. 
From  $\dom(S) = \dom(ST)$ we deduce that $b \in \dom(ST)$, namely that
for some $c' \in \dom(T)$ and $d$ we have $b S c' T d$. From $a R b S c' T d$ we conclude
that $a \in \dom(RST)$, as wished.

\end{enumerate}
\end{proof}

The inclusion $\dom(RS) \subseteq \dom(R)$ proved in
Lemma \ref{lemma-domain-inclusion}.\ref{lemma-domain-inclusion-01}
is often strict. An example: if $R = \{(1,1)\}$ and $S = \{(2,2)\}$ then $RS=\emptyset$,
therefore $\dom(RS) = \emptyset \subset \dom(R) = \{1\}$. 
We call domain-stable any sequence $\vec{R}$ of relation in which this never happens.
 
\begin{definition}[Domain-Stability]
Let $R$, $S$ be any two relations and $\vec{S}=S_1, \ldots, S_n$ be any sequence of relations. 
\begin{enumerate}

\item
We say that a pair $R, S$ is \emph{domain-stable}, only \emph{stable} for short, if 
and only if $\dom(R) = \dom(RS)$.

\item
$\vec{S}$ is stable if and only if for all $i \in [1,n-1]$
the pair $S_i$, $S_{i+1}$ is stable.

\end{enumerate} 
\end{definition}


A sequence of length $n=0,1$ is trivially stable because $[1,n-1] = \emptyset$.
By Lemma \ref{lemma-domain-inclusion}.\ref{lemma-domain-inclusion-03} we can
restate domain-stability in several ways. We have
$R,S$ stable $ \Leftrightarrow (\dom(R) = \dom(RS))  
  \Leftrightarrow  
(\dom(R) \subseteq \dom(RS)) 
  \Leftrightarrow   
(\dom(R) \not \supset  \dom(RS))
$.

In particular, $R,S$ stable means that $(\dom(R) \subseteq \dom(RS))$, 
namely that whenever $x$ has an $R$-image $y$, then $x$ has some
$R$-image $y'$ having some $S$-image $z$. It does \emph{not} say, however,
that each $R$-image of $x$ has some $S$-image: it only says that if $x$ has some
$R$-image, then some of the $R$-images of $x$ have some $S$-image. 
In the same way we can restate the stability for a sequence.

\begin{proposition}[Restating Stability]
Let $\vec{S}=S_1, \ldots, S_n$ be any sequence of relations. 
Then  $\vec{S}$ is stable if and only if $S_i \restr \dom(S_i) \times \dom(S_{i+1})$ 
is everywhere defined for all $i \in [1,n-1]$. 
\end{proposition}

\begin{proof}
Indeed, this is just another way of saying that if $x$ has some $S_i$-image,
then some $S_i$-image of $x$ has some $S_{i+1}$-image. This is the definition
of $S_i$, $S_{i+1}$ domain-stable for $i \in [1,n-1]$. 
\end{proof}

Domain-stable sequences satisfy more domain equalities than generic sequences.

\begin{lemma}[Domain-Stability]
\label{lemma-domain-stability}
Let $\vec{S}=S_1, \ldots, S_n$ be any sequence of relations. The following are equivalent:

\begin{enumerate}
\item
\label{lemma-domain-stability-01}
$\vec{S}$ is stable

\item
\label{lemma-domain-stability-02}
for all $i, j \in [1, n]$, $i \le j$ we have:
$$
\dom(S_i) =  \dom(S_i \ldots S_j)
$$

\item
\label{lemma-domain-stability-03}
all grouping and all prefixes of $\vec{S}$ are stable.

\item 
\label{lemma-domain-stability-04}
for all $i \in [1,n-1]$ we have:
$$
\dom(S_i) = \dom(S_i \ldots S_n)
$$

\end{enumerate}



\end{lemma}

\begin{proof}
We first prove the equivalence of points 
\ref{lemma-domain-stability-01},
\ref{lemma-domain-stability-02},
\ref{lemma-domain-stability-03},
namely we prove that
\begin{center}
\ref{lemma-domain-stability-01} 
$\implies$ 
\ref{lemma-domain-stability-02}
$\implies$ 
\ref{lemma-domain-stability-03} 
$\implies$ 
\ref{lemma-domain-stability-01}
\end{center}
Then we prove the equivalence of points
\ref{lemma-domain-stability-02},
\ref{lemma-domain-stability-04},
by proving that 
\begin{center}
\ref{lemma-domain-stability-02} $\implies$  
\ref{lemma-domain-stability-04} $\implies$  
\ref{lemma-domain-stability-02}
\end{center}


\begin{enumerate}


\item
\ref{lemma-domain-stability-01} $\implies$ \ref{lemma-domain-stability-02}.

We assume point \ref{lemma-domain-stability-01}: $\vec{S}$ is stable, in to prove 
point \ref{lemma-domain-stability-02}: 
for all $i, j \in [1, n]$, $i \le j$ we have $\dom(S_i) =  \dom(S_i \ldots S_j)$.

For, we assume $j \ge i$ and we prove $\dom(S_i) =  \dom(S_i \ldots S_j)$ by induction on $j$.
\begin{enumerate}
\item
Assume $j=i$. Then $\dom(S_i) =  \dom(S_i)$.
\item
Assume $\dom(S_i) =  \dom(S_i \ldots S_j)$ and $j<n$ in order to prove that 
$\dom(S_i) =  \dom(S_i \ldots S_j S_{j+1})$. By defiition of stability we have 
$\dom(S_j) = \dom(S_j S_{j+1})$. By Lemma 
\ref{lemma-domain-inclusion}.\ref{lemma-domain-inclusion-04} 
applied to $(S_i \ldots S_{j-1}), \ S_j, \ S_{j+1}$ we deduce 
$\dom( (S_i \ldots S_{j-1}) S_j) = \dom( (S_i \ldots S_{j-1}) S_j S_{j+1})$.
From the inductive hypothesis $\dom(S_i) =  \dom( (S_i \ldots S_{j-1}) S_j)$
we conclude that $\dom(S_i) =  \dom((S_i \ldots S_{j-1}) S_j S_{j+1})$, as wished.
\end{enumerate}


\item
\ref{lemma-domain-stability-02} $\implies$ \ref{lemma-domain-stability-03}.

We assume point \ref{lemma-domain-stability-02}: 
for all $i, j \in [1, n]$, $i \le j$ we have $\dom(S_i)  =  \dom(S_i \ldots S_j)$,
in order to prove point \ref{lemma-domain-stability-03}:
all prefixes and grouping of $\vec{S}$ are stable. 

All prefixes are stable because the finite quantification defining stability for a prefix 
is a restriction of the finite quantification defining stability for the sequence. 

We prove that all grouping are stable. We assume that
$i, j,k\in [1, n]$, $i \le j < k$ and that $S_i \ldots S_j$, $S_{j+1} \ldots S_k$
are two consecutive products in some grouping of $\vec{S}$, and we have to prove 
that $\dom(S_i \ldots S_j) = \dom( (S_i \ldots S_j) (S_{j+1} \ldots S_k))$. 
By point \ref{lemma-domain-stability-02} we have 
$$
\dom(S_i \ldots S_j) = \dom(S_i) = \dom(S_i \ldots S_j S_{j+1} \ldots S_k)
$$
This proves point \ref{lemma-domain-stability-03}.


\item
\ref{lemma-domain-stability-03} $\implies$ \ref{lemma-domain-stability-01}.

We assume point \ref{lemma-domain-stability-03}: all prefixes 
and grouping of $\vec{S}$ are stable,
and we have to prove point \ref{lemma-domain-stability-01}: $\vec{S}$ is stable. 

This follows from the fact that $\vec{S}$ is a trivial case of grouping of $\vec{S}$.


\item
\ref{lemma-domain-stability-02} $\implies$  \ref{lemma-domain-stability-04}.
We assume point \ref{lemma-domain-stability-02}:
for all $i, j \in [1, n]$, $i \le j$ we have $\dom(S_i) =  \dom(S_i \ldots S_j)$
and we have to prove point \ref{lemma-domain-stability-04}: 
for all $i \in [1, n-1]$ we have $\dom(S_i) =  \dom(S_i \ldots S_n)$.

This follows by choosing $j=n \ge i$.


\item
\ref{lemma-domain-stability-04} $\implies$  \ref{lemma-domain-stability-02}.

We assume point \ref{lemma-domain-stability-04}: 
for all $i \in [1, n-1]$ we have $\dom(S_i) =  \dom(S_i \ldots S_n)$, and we have to prove
point \ref{lemma-domain-stability-02}: 
for all $i, j \in [1, n]$, $i \le j$ we have $\dom(S_i) =  \dom(S_i \ldots S_j)$.

\emph{Suppose $i=n$}. 
Then the thesis becomes $\dom(S_n) =  \dom(S_n)$, which is trivially true.

\emph{Suppose $i \in [1,n-1]$}.
By Lemma \ref{lemma-domain-inclusion}.\ref{lemma-domain-inclusion-01},
for each sequence $\vec{S}$ of relations we have 
$$
\dom(S_i)  \ \ \ \supseteq \ \ \ 
\dom(S_iS_{i+1})  \ \ \  \supseteq \ \ \ 
\dom(S_iS_{i+1}S_{i+2})  \ \ \  \supseteq  \ \ \ 
\ldots  \ \ \  \supseteq  \ \ \ 
\dom(S_i \ldots S_n)
$$ 
therefore if we add the assumption $\dom(S_i \ldots S_n) = \dom(S_i)$ we conclude that
$$
\dom(S_i)   \ \ \ =  \ \ \ 
\dom(S_iS_{i+1})  \ \ \  =  \ \ \ 
\dom(S_iS_{i+1}S_{i+2})   \ \ \ =  \ \ \ 
\ldots   \ \ \ =  \ \ \ 
\dom(S_i \ldots S_n)
$$ 
as wished.
 
\end{enumerate}
\end{proof}

Lemma \ref{lemma-domain-stability}.\ref{lemma-domain-stability-02}
says that a sequence is stable if and only if whenever $x$ has some $S_i$-image,
then $x$ has some chain of $S_i, S_{i+1}, S_{i+2}, \ldots$-images of any length
moving through the sequence. This is an alternative definition of domain-stable sequence.

We compare two groupings, looking for the grouping whose product in front are shorter.

\begin{definition}[Lexicographic Ordering on Grouping]
\label{definition-grouping-order}
Assume $\vec{S}=S_1, \ldots, S_n$ is a sequence of relations and 
$$
\vec{R} \ \ \ = \ \ \ 
S_{a_1} \ldots S_{b_1}, \ \ \ S_{a_2} \ldots S_{b_2}, \ \ \ \ldots, \ \ \ S_{a_{h+1}} \ldots S_{b_{h+1}}
$$
is a grouping of $\vec{S}$ with $a_1=1, a_{i+1} = b_i+1$ for all $i \in [1,h]$ and 
$b_{h+1} = n$.

\begin{enumerate}
\item
The degree of the grouping $\vec{R}$ of $\vec{S}$ is the sequence
of the lengths of its products, namely $(b_1, b_2 - b_1, \ldots, b_{h+1} - b_h)$. 
\item
We compare two grouping of the same sequence by comparing their degrees in the 
lexicographic ordering.
\end{enumerate}
\end{definition} 

For instance, 
$S_1 \ldots S_n$ is the maximum grouping and $S_1, \ldots, S_n$ the minimum grouping.

We us order on grouping to select a simplest stable grouping.
All sequences $\vec{S}=S_1, \ldots, S_n$ have a trivial stable grouping, by taking the
product $S_1 \ldots S_n$ of the sequence. This is the maximum grouping, 
and therefore it is the maximum stable grouping, but it is trivial.

Lexicographic ordering is total, therefore there is a minimum stable grouping.

We provide an alternative characterization of the minimum stable grouping, then using

\begin{definition}[Stable Matching]
Let $i \in [1,n]$. We say that $j \in [i,n]$ is a stable matching of $i$ in $\vec{S}$
if and only if $\dom(S_i \ldots S_j) = \dom(S_i \ldots S_n)$.
\end{definition}

By definition unfolding, $j \in [i,n]$ is a stable matching of $i$ in $\vec{S}$
if and only if all $x \in [1,\MaxInd]$ having some $S_i \ldots S_j$-image have some
$S_i \ldots S_n$-image and conversely. 

$j=n$ is trivially a stable matching of any $i \in [1,n]$.

\begin{definition}[Minimum Stable Matching $\phi(\vec{S},i)$]
We define the integer $\phi(\vec{S},i) \in [i,n]$ as the minimum stable matching $j\in [i,n]$ 
of $i$ in $\vec{S}$. We write $\phi(i)$ when $\vec{S}$ is clear from the context,
\end{definition}


\begin{lemma}[Characterization of $\phi(\vec{S},i)$]
\label{lemma-phi-characterization}
We have $\phi(\vec{S} S_{n+1}, n+1) = n+1$ and for all $i \in [1,n]$
one of the following holds:
\begin{enumerate}
\item
either $\dom(S_i \ldots S_n) = \dom(S_i \ldots S_n S_{n+1})$
and $\phi(\vec{S}S_{n+1},i) = \phi(\vec{S},i)$;
\item
or $\dom(S_i \ldots S_n) \supset \dom(S_i \ldots S_n S_{n+1})$
and $\phi(\vec{S}S_{n+1},i) = n+1$.
\end{enumerate}
$\phi(\vec{S},\cdot):[1,n] \rightarrow [1,n]$ is a weakly increasing map.
\end{lemma}

\begin{proof}
$\phi(\vec{S} S_{n+1}, n+1) = n+1$ follows from $\phi(\vec{S} S_{n+1}, n+1) \ge n+1$
and $\phi(\vec{S} S_{n+1}, n+1) \in [1,n+1]$. 
By Lemma \ref{lemma-domain-inclusion}.\ref{lemma-domain-inclusion-01}, 
either $\dom(S_i \ldots S_n) = \dom(S_i \ldots S_n S_{n+1})$ 
or $\dom(S_i \ldots S_n) \supset \dom(S_i \ldots S_n S_{n+1})$. 
\begin{enumerate}
\item
\emph{Suppose $\dom(S_i \ldots S_n) = \dom(S_i \ldots S_n S_{n+1})$}.
Then for $j = \phi(\vec{S},i)$
we have $\dom(S_i \ldots S_j) = \dom(S_i \ldots S_n) = \dom(S_i \ldots S_n S_{n+1})$,
while for all $k<j$ we have 
$\dom(S_i \ldots S_k) \not = \dom(S_i \ldots S_n) = \dom(S_i \ldots S_n S_{n+1})$.
This implies $\phi(\vec{S}S_{n+1},i) = \phi(\vec{S},i)$

\item
\emph{Suppose $\dom(S_i \ldots S_n) \supset \dom(S_i \ldots S_n S_{n+1})$}.
Then for all $j \in [i,n]$, $j \ge i$ 
by Lemma \ref{lemma-domain-inclusion}.\ref{lemma-domain-inclusion-02} 
we have 
$\dom(S_i \ldots S_j)  \supseteq \dom(S_i \ldots S_n) \supset \dom(S_i \ldots S_n S_{n+1})$.
We deduce $\phi(\vec{S}S_{n+1},i) >n$ 
and we conclude that $\phi(\vec{S}S_{n+1},i) = n+1$.

\end{enumerate}

Now we check that $\phi$ is weakly increasing.

We assume $i,j \in [1,n]$, $i < j$ in order to prove that $\phi(\vec{S},i) \le \phi(\vec{S},j)$.
Let $b =  \phi(\vec{S},j)$. Then by definition of $\phi$ we have

$\dom((S_i \ldots S_{j-1}) S_j \ldots S_b) = \dom((S_i \ldots S_{j-1}) S_j \ldots S_n)$.
By definition of $\phi$, this implies $\phi(\vec{S},i) \le b =  \phi(\vec{S},j)$,
as wished.
\end{proof}

\begin{lemma}[Injective Relation Sequences]
\label{lemma-stable-sequences}
Assume $R, S$, $\vec{R}=R_1, \ldots, R_n$ all are \emph{injective} relations.
\begin{enumerate}
\item
$\Card(\dom(RS)) \le \Card(\dom(S))$
and if $\Card(\dom(RS)) \le \Card(\dom(S))$ then $R$ restricted to $\dom(R) \times \dom(S)$
is a bijection.

\item
$$
\Card(\dom(R_1 \ldots R_n)) \le \Card(\dom(R_2 \ldots R_n)) \le \ldots \le \Card(\dom(R_n))
$$

\item
If  $i, j \in[1,n]$ and $i < j$ and $\Card(\dom(R_i \ldots R_n)) = \Card(\dom(R_j \ldots R_n))$
then $R_i \ldots R_{j-1}$ restricted to $\dom(R_i \ldots R_n) \times \dom(R_j \ldots R_n)$
is a bijection.
\end{enumerate}
\end{lemma}

\begin{proof}
\begin{enumerate}

\item
for all $x \in \dom(RS)$ the sets $X_x = \{ y \in \dom(S) | x R y \}$ are inhabited,
because if $x \in \dom(RS)$ then for some $y \dom(S), z$ we have $x R y z$.
They are pairwise disjoint subsets of $\dom(S)$, because $R$ is injective. We deduce that 
$\Card(\dom(RS)) \le \Card(\bigcup_{x \in \dom(RS)} X_x) \le \Card(\dom(S))$.

Now assume that $\Card(\dom(RS)) = \Card(\dom(S))$. Then 
$\Card(\dom(RS)) = \Card(\bigcup_{x \in \dom(RS)} X_x) = \Card(\dom(S))$. 
From $\Card(\bigcup_{x \in \dom(RS)} X_x) = \Card(\dom(S))$, 
$\bigcup_{x \in \dom(RS)} X_x \subseteq \dom(S)$ and $\dom(S)$ finite we deduce
that $\bigcup_{x \in \dom(RS)} X_x = \dom(S)$. 
From the fact that all $\Card(\dom(RS)) = \Card(\dom(S))$ and all $X_x$ are inhabited we 
deduce that all $X_x$ are singleton. This says that $R$ restricted to $\dom(R) \times \dom(S)$
is a bijection.

\item
Let $i \in [1,n-1]$.
From the point 1 above applied to $R = R_i$, $S = R_{i+1}\ldots R_n$ we deduce that
$\Card(\dom(R_i R_{i+1}\ldots R_n)) \le \Card(\dom(R_{i+1} \ldots R_n))$

\item
$i, j \in[1,n]$ and $i < j$ and $\Card(\dom(R_i \ldots R_n)) = \Card(\dom(R_j \ldots R_n))$.
From the point 1 above applied to $R = R_i \ldots R_{j-1}$, $S = R_i \ldots R_{j-1}$ 
we deduce that $R_i \ldots R_{j-1}$ restricted to 
$\dom(R_i \ldots R_{j-1} \ldots R_j \ldots R_n) \times \dom(R_i \ldots R_{j-1})$
is a bijection.

\end{enumerate}
\end{proof}

\begin{lemma}[Injective Domain-Stable Relation Sequences]
\label{lemma-injective-stable-sequences}
Assume $\vec{R}=R_1, \ldots, R_n$ is a \emph{domain-stable}
sequence of injective relations.
\begin{enumerate}
\item
\label{lemma-injective-stable-sequences-01}
$$
\Card(\dom(R_1)) \le \Card(\dom(R_2)) \le \ldots \le \Card(\dom(R_n))
$$

\item
\label{lemma-injective-stable-sequences-02}
If  $i, j \in[1,n]$ and $i \le j$ and $\Card(\dom(R_i)) = \Card(\dom(R_j))$
then $R_i \ldots R_j$ has domain $\dom(R_i)$ and
when restricted to $\dom(R_i) \times \dom(R_j)$
is a bijection.
\end{enumerate}
\end{lemma}

We define constant-cardinality domain and weakly-increasing cardinality domain.

\begin{definition}[Constant-Cardinality Domain and Weakly-increasing Cardinality Domain]
Assume $\vec{S}=S_1, \ldots S_n$ is any sequence of relations.
\begin{enumerate}
\item
$\vec{S}$ is a constant-cardinality domain sequence if and only if for all $i,j \in [1,n]$:
$$
\Card(\dom(S_i)) = \Card(\dom(S_j))
$$
If $\vec{S}$ is not empty then we call $\Card(S_1)$ the domain-cardinality of $\vec{S}$.

\item
$\vec{S}$ is a weakly-increasing-cardinality-domain sequence if and only if 
for all $i,j \in [1,n]$, $i \le j$:
$$
\Card(\dom(S_i)) \le \Card(\dom(S_j))
$$
\end{enumerate}
\end{definition}

Lemma  \ref{lemma-injective-stable-sequences}.\ref{lemma-injective-stable-sequences-01}
says that every injective domain-stable sequence is a weakly-increasing-cardinality-domain
sequence.

Every weakly-increasing-cardinality-domain sequence $\vec{S}$ can be decomposed in a 
unique way into a concatenation of non-empty constant-cardinality-domain sequences with 
increasing cardinality domain. Namely we have:
$$
\vec{S}
=
S_{a_1},\ldots,S_{b_1}
\ldots
S_{a_{h}},\ldots,S_{b_{h}}
$$
with each $S_{a_{i}},\ldots,S_{b_{i}}$ constant cardinality domain and 
$\Card(\dom(S_{a_i})) < \Card(\dom(S_{a_j}))$ for all $i,j \in [1,h]$, $i < j$.
We call each subsequence $S_{a_{i}}, \ldots, S_{b_{i}}$ 
a constant-cardinality-domain component of $\vec{S}$.

\begin{lemma}
\begin{enumerate}
\item
If $i,j \in [1,n]$, $i<j$ and $D_i = D_j$ then $R_i \ldots R_j$ is progressing on $D_i$.
\item
If  $i,j \in [1,n]$, $i<j$ and $\Card(D_i) = \Card(D_j)$ and $j-i \ge 2^{\MaxInd}$ 
then $R_i \ldots R_j$ is progressing on $D_i$.
\end{enumerate}
\end{lemma}

We assume having for each predicate a size map $\size : Assignements, 
[1,\MaxInd] \rightarrow \N$,
such that if $q(\vec{u})$ is the inductive formula number $i$, if $q(\vec{t})$ is the inductive
formula number $j$ and $\sigma$ is an assigment, and $q(\sigma(\vec{u}))$ is an assumption
of the proof of $q(\sigma(\vec{t}))$, then $\size(\sigma,i) < \sigma(\sigma,j)$. We usually 
skip $\sigma$ and we write $\sigma(i), \sigma(j)$.

We include some examples of size map. The first example is the size map counting the
inductive rules in the proof of $q(\vec{t})$.

\begin{enumerate}
\item 
if $q(\vec{t}) = \N(v)$, then $$\sigma(i)=v+1$$ because if $v$ has value $a$ 
then $v=S^a(0)$ and the proof of $\N(v)$ has $a$ times an $S$-rule and $1$-time
the $0$-rule.

\item
If $q(\vec{t}) = \List(l)$ states that $l$ is a list on $\N$, 
then $$\size(i) = (\length(l)+1)+\Sigma_{i=1}^{i=\length(l)}(l[i]+1)$$
Here we count $\length(l)$ times the rule $\cons$, once the rule $\nil$,
the we add the total size of all elements of $l$.

\item
If $q(\vec{t}) = \Tree(t)$ states that $t$ is a binary tree with labels in $\N$, 
then $\size(i)$ is any expression counting the number of rules for nodes in $t$, plus the size
of all labels of $t$.
\end{enumerate}

Alternatively, the size map can count the maximum nesting of inductive rules in the proof of $q(\vec{t})$. In this case the size of $\N(v)$ is $v$ itself.

We claim that after at most $2^\MaxInd$ steps any constant-domain sequence progresses.
We formally express this fact through the notion of degree.

\begin{definition}[Degree of an Index in a Domain-Stable Injective Sequence]
The degree $\deg(j,\vec{R})$ of $j \in [1,n]$ in 
$\vec{R} = R_1, \ldots, R_n$ as above is $2^\MaxInd-1-d$, for $d$ the minimum distance of
an index $i \le j$ such that at least one of the following happens:
\begin{enumerate}
\item
$i=1$
\item
$i>1$ and $\Card(D_{i-1}) < \Card(D_j)$
\item
$R_{i} \ldots R_j$ is progressing between $D_i$ and $D_j$.
\end{enumerate}
If $X \subseteq [1,\MaxInd]$, we set $\size(X) = \Sigma_{i \in X} \size(i)$.
\end{definition}
 
Suppose that in a given node of the proof and for $i \in [1, \MaxInd]$ 
the inductive expression number $i$ is $q(\vec{t})$. Then $\size(i)$ is any expression
of the language computing, in any assignment $\sigma$ to the variable of the node, 
the number of constructors in $\sigma(\vec{t})$. Any map returning a positive integer
and increasing w.r.t. the subterm relation would work. 



If $\vec{R} = R_1, \ldots, R_n \in \setR^+$ is stable then we will define a size for $\vec{R}$: 
$\size(\vec{R})$. We need the stability assumption for $\vec{R}$, 
otherwise we cannot prove that 
the size is a decreasing map. For a generic injective sequence $\vec{S}$, we will first compute
the Minimum Stable Grouping of $\vec{S}$.

\begin{definition}[Size of an Injective Sequence]
If $\dom(R)$ is any injective domain-stable sequence then we set:
$$
\size(\vec{R}) 
= 
(c_1, \size(D_{a_1}), \deg(a_1,\vec{R}), \ldots,c_h,\size(D_{a_h},\deg(a_h,\vec{R}))
$$
If $\dom(S)$ is any injective sequence then we set $\size(\vec{R}) = \size(\minStable(\vec{S}))$.
\end{definition}

If $\vec{R}$ is stable then $\minStable(\vec{R}) = \vec{R}$, therefore 
the general definition includes the definition for the stable case.

The corresponding state for the algorithm translating a cyclic proof into an
injective proof is $\state(\vec{R})$, defined as follows.

\begin{definition}[State of an Injective Domain-Stable Sequence]
If $\dom(R)$ is any injective domain-stable sequence then we set:
$$
\state(\vec{R})
=
(c_1, R_{a_1}\ldots R_{a_2-1}, \deg(a_1,\vec{R}), 
\ldots,
c_h, R_{a_h}\ldots R_{n}, \deg(a_h,\vec{R}))
$$
If $\dom(S)$ is any injective sequence then we set $\state(\vec{R}) = \state(\minStable(\vec{S}))$.
\end{definition}
 
We prove that adding any $R_{n+1}$ to the sequence reduces the index in the 
lexicographic ordering: $\size(\vec{R}) > \size(\vec{R}R_{n+1}) $. Besides,
$\size(\vec{R})$ can be computed from $\state(\vec{R})$. Indeed, if
$\vec{R} = \minStable(\vec{S})$, then $\vec{R}$ is stable and

$$
\size(\vec{S})
=
\size(\vec{R})
=
(
 c_1,(\dom(R_{a_1}\ldots R_{a_2-1}), \deg(a_1,\vec{R}), 
 \ldots,
 c_h,\dom(R_{a_h}\ldots R_{n}), \deg(a_h,\vec{R})
 )
$$

We can compute $\state(\vec{S}S_{n+1})$ from $\state(\vec{S})$.
There are six cases. Suppose $\minStable(\vec{S}) = \vec{R}$.
We have $\Card(\dom(S_{n+1}) \ge c_h$.

\begin{enumerate}
\item
Suppose$ \vec{R}S_{n+1}$ is stable and $\Card(\dom(R_{n+1})> c_h$. Then
$c_{h+1} = \Card(\dom(R_{n+1})$, $a_h = n$, $a_{h+1} = n+1$ and 
$\state(\vec{S}S_{n+1})$ is 

$$
(c_1, R_{a_1}\ldots R_{a_2-1}, \deg(a_1,\vec{R}), 
\ldots,
c_h, R_{a_h}, \deg(a_h,\vec{R}),
c_{h+1}, S_{n+1}, 2^{\MaxInd} - 1)
$$

\item
Suppose$ \vec{R}S_{n+1}$ is stable and $\Card(\dom(R_{n+1})= c_h$
and $R_n S_{n+1}$ is progressing on $\dom(R_{n})$.
Then the new value of $a_h$ is $n+1$ and $\state(\vec{S}S_{n+1})$ is 

$$
(c_1, R_{a_1}\ldots R_{a_2-1}, \deg(a_1,\vec{R}), 
\ldots,
c_{h-1}, R_{a_{h-1}}\ldots R_{a_h}, \deg(a_h,\vec{R}),
c_{h}, S_{n+1}, 2^{\MaxInd} - 1)
$$

\item
Suppose$ \vec{R}S_{n+1}$ is stable and $\Card(\dom(R_{n+1})= c_h$
and $R_n S_{n+1}$ is stationary on $\dom(R_{n})$.

Then $\state(\vec{S}S_{n+1})$ is 

$$
(c_1, R_{a_1}\ldots R_{a_2-1}, \deg(a_1,\vec{R}), 
\ldots,
c_{h-1}, R_{a_{h-1}}\ldots R_{a_h}, \deg(a_h,\vec{R}),
c_{h}, S_{n+1}, \deg(a_h,\vec{R}) - 1)
$$

\item
Suppose$ \vec{R}S_{n+1}$ is not stable and $j \in [1,n]$ is the first index
such that $\dom(R_j \ldots R_n) \supset \dom(R_j \ldots R_n S_{n+1})$.
Then $j = a_i + 1$ for some $i$ and the Minimum Stable grouping of $\vec{S}S_{n+1}$
is $R_1, \ldots, R_{a_i}, R$ with $R = R_j \ldots R_n S_{n+1}$. If $R_{a_i} R$
is progressing on $\dom(R_{a_i})$ then the new value of $a_i$ is
$a_{i+1}$ and $\state(\vec{S}S_{n+1})$ is 

$$
(c_1, R_{a_1}\ldots R_{a_2-1}, \deg(a_1,\vec{R}), 
\ldots,
c_{i-1}, R_{a_{i-1}}\ldots R_{a_i}, \deg(a_i,\vec{R}),
c_{i}, R, 2^{\MaxInd}-1)
$$

\item
If instead $R_{a_i} R$
is stationary on $\dom(R_{a_i})$ then $\state(\vec{S}S_{n+1})$ is:

$$
(c_1, R_{a_1}\ldots R_{a_2-1}, \deg(a_1,\vec{R}), 
\ldots,
c_{i-1}, R_{a_{i-1}}\ldots R_{a_i}R, \deg(a_i,\vec{R})-1)
$$

\end{enumerate}


The number of states is bounded by 
$
(2^{O(\MaxInd^2)} \times 2^\MaxInd \times \MaxInd)
\times \ldots \times
(2^{O(\MaxInd^2)} \times 2^\MaxInd \times \MaxInd)
$,
with at most $3\MaxInd$ product. 
We conclude that it is bounded by $2^{O(\MaxInd^3)}$. Each step requires time bounded by
$O(2^{\MaxInd^2}) \times \log_2(2^{O(\MaxInd^3)})$. 
We have $n \le 2^{\MaxInd^2}$, and cyclically 
for each $R_i$ with $i = 1, \ldots, n$ we add the state obtained by concatenating with 
$R_i$ and we compare it with the existing states sorted, in order to decide whether it is a new
state or not. We stop adding states in the first cycle we add no new state.
The total time cost is bounded by the number of relations times the cost of checking
whether we have a new state times the upper bound to the number of states.
The total is $O(2^{\MaxInd^2}) \times {O(\MaxInd^3)} \times 2^{O(\MaxInd^3)}$,
namely it is $2^{O(\MaxInd^3)}$ again. Therefore the total cost is poly-exponential.

We define a ranking function. Assume $\vec{S}$ has minimum stable grouping 
$\vec{R} = R_1, \ldots, R_n$.
The size $\size(\vec{S})$ of the state of $\vec{S}$ are made with the size of the domains
$\dom(R_{a_1}\ldots R_{a_2-1}), \ldots, \dom(R_{a_h}\ldots R_{n})$, whose
cardinality are, respectively, $c_1, \ldots, c_h$, and whose total cardinality is 
$c_1 + \ldots c_h$, which is $\le 1+\ldots+\MaxInd = \MaxInd(\MaxInd+1)/2$. We add
this number of variables and we assume the set $Eq(\vec{S})$ of equations and unequations 
between old and new variables which are expressed by $R_1, \ldots, R_n$. 
We choose any vector $\vec{z}$ of length $\le \MaxInd$, each bud of the proof, we assume that if $Eq(\vec{S})$ holds and $\size(\vec{S}) < \vec{z}$ 
then the cyclic proof derives the conclusion whenever $Eq(\vec{S})$ holds and 
$\size(\vec{S}) \le \vec{z}$. In particular the conclusion is true when $\vec{S}=$ empty, 
$Eq(\vec{S}) = \emptyset$ and $\vec{z} = (z) = \size(\vec{S}) = $ the sum of sizes of
the inductive formulas in the left-hand-side of the conclusion. 

This derives the conclusion, as wished.
