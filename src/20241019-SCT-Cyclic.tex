\section{Introduction}
We want to study Size Change Termination condition 
(from now on, SCT) for program termination, introduced by
Chin Soon Lee, Neil D. Jones and Amir M. Ben-Amram in \cite{2001-SCT}
in a particular case relevant for cyclic proofs. 
We are interested to the case of transition graphs labeled by 
\emph{injective} bi-colored relations.

Our motivation is that this particular case of SCT is enough to check 
the correctness of a cyclic proof. 
Cyclic proofs have been introduced independently as a tool for proof search
by Brotherston and Simpson \cite{2011-Brotherston-Simpson}. 
Later, the algorithm checking correctness cyclic proofs turned out to be
a particular case of the algorithm checking the SCT condition for programs.

The algorithm checking SCT is PSPACE-complete (\cite{2001-SCT}).
SCT is PSPACE-complete 
also in the particular case of injective bi-colored relations required by cyclic 
proofs (\cite{2009-Lee-Aram}). 
However we will argue that checking SCT is simpler  
and faster in this case.



We prove termination for SCT in the case of injective relations only using 
first order induction. We use Intuitionistic Logic and Peano Induction only.
With respect to the proof included in \cite{2009-Lee-Aram} (where the injectivity condition is called the \emph{fan-in-free} condition), we try to reduce
the proof size. This is because
our long-term goal is to define an automatic translation from 
cyclic proofs into more ordinary inductive proofs. This translation
would be useful for cross-checking the result of a proof-search done 
using cyclic proofs using an ordinary proof assistant not including cyclic proofs. 
We do not have such a translation yet, but we believe that from
a shorter termination proof for SCT we will be able to define a simpler
translation from cyclic proofs to inductive proofs. 


\section{Size Change Termination in the Case of Injective Relations}
%14:03 30/10/2024 
Along this paper we suppose we have the main ingredients for an SCT problem,
namely:
\begin{enumerate}
\item
a \emph{finite set} $X=\{x_1, \ldots, x_n\}$, representing variables;

\item
a finite set $\setR$, with
each $(\Stat, \Prog) \in \setR$ a \emph{pair of finite relations on $X$}
such that \emph{$\Stat \cap \Prog = \emptyset$ for all $(\Stat, \Prog) \in \setR$},
representing bi-colored relations on variables;

\item
a finite non-empty set $G$, representing abstract program states, 
and a map $\setG: \dom(\setG) \rightarrow \setR$,
such that $\dom(\setG) \subseteq G \times G$. 
\end{enumerate}

Implicitly, $\setG$ defines a labeled transition graph on program states.
The set of nodes of the graph is $G$, the set of
edges is $\dom(\setG) \subseteq G \times G$ and each edge $(a,b)$
is labeled by some $\setG(a,b) \in \setR$. 

We call each $(\Stat, \Prog) \in \setR$ just a \emph{pair} for short.
If $x \Stat y$ we say that $x$ weakly progresses to $y$ in $(\Stat, \Prog)$,
and if $x \Prog y$ we say that $x$ progresses to $y$ in $(\Stat, \Prog)$.
Each label $\setG(a,b)  \in \setR$ on a transition from $a$ to $b$ in $G$ represented all
we know about the relationship between the values of any two variables $x$, $y$ before
and after the transition: either weak progression, or strict progression, 
or no information at all, in the case $x \Stat y$ and $x \Prog y$ are both false.

We define composition of pairs in $\setR$ by:
$$
\Stat'' = \Stat \Stat', 
\ \ \ 
\Prog'' = \Stat \Prog' \cup \Prog \Stat' \cup \Prog \Prog'
$$
$$
(\Stat,\Prog)(\Stat',\Prog') 
=
(\Stat''\setminus\Prog'', \Prog'')
$$
By definition, the result of composition is a \emph{disjoint} 
pair of finite relations on $X$, therefore again a bicolored relation.
Two pairs are composable if they label some transition sequence in the
graph defined by $\setG$.


\begin{definition}[Composable pairs  in $\setG$]
Assume $\setR, \setG$ are as above.

\begin{enumerate}

\item
We write $\composable{\setG}{a}{b}{(\Stat,\Prog)}$
for the smallest relation including $\setG(a,b) = (\Stat,\Prog)$ and closed
by composition: if $\composable{\setG}{a}{b}{(\Stat,\Prog)}$ and
$\composable{\setG}{b}{c}{(\Stat',\Prog')}$ then  
$\composable{\setG}{a}{c}{(\Stat,\Prog)(\Stat',\Prog')}$.


\item
We say that that two pairs of finite disjoint relations $(\Stat,\Prog), (\Stat',\Prog')$ on 
$X$ are \emph{composable in $\setG$}, just \emph{composable} for short
if and only if we have
$\composable{\setG}{a}{b}{(\Stat,\Prog)}$ and
$\composable{\setG}{b}{c}{(\Stat',\Prog')}$ for some $a,b,c, \in G$.

\item
We say that $(\Stat,\Prog) \in \setR$
is \emph{self-composable in $\setG$}, just \emph{self-composable}
for short, if and only if we have 
$\composable {\setG} {a} {a} {(\Stat,\Prog)}$ for some $a \in G$.

\end{enumerate}

\end{definition}

We skip the index $\setG$ when it can be deduced from the context
and we write just $\composable{}{a}{b}{(\Stat,\Prog)}$.
The role of $\setG$ is to restrict the set of compositions which are allowed.

As we said, we consider the elements of $X$ as variables to which we associate a value 
in each instant of time. A a consequence, 
we will use each relation $x \Stat y$ to express the fact that 
$x$ is associated in an instant $t$ to x value \emph{greater than or equal} 
to the value associated to $y$ in the next instant $t+1$.
We will use each relation $x \Prog y$ to express the fact that $x$
is associated in an instant $t$
to x value \emph{greater than} the value associated to $y$ in the next
instant $t+1$.
\\

The requirement $\Stat \cap \Prog = \emptyset$ 
on any $(\Stat,\Prog) \in \setR$ expresses the fact that
if we know that $x \Prog y$ (namely that
the value of of $x$ is greater than the value of $y$), then the information
$x \Stat y$ (namely that the value of of $x$ is greater \emph{or equal} 
than the value of $y$) becomes redundant and we remove it from our records.
Alternatively, the condition $\Stat \cap \Prog = \emptyset$ is required for
$(\Stat,\Prog)$ to define a bicoloring on $\Stat \cup \Prog$ as done in
\cite{2001-SCT}.
\\

We call \emph{trace} any sequence on $X$. 
We call \emph{path} on $\setG$ 
any transition path in the graph defined by $\setG$.
Alternatively, a path any sequence $b$ on $G$ such that $(b(i),b(i+1)) \in 
\dom(\setG)$ for any two consecutive elements of the path.
Each path is a path in the graph associated to $G$ and labeled on $\setR$ by $\setG$.
Thus, each path $b$ is associated by $\setG$ to a sequence $r$ on $\setR$
defined by $r(i) = (\Stat_i, \Prog_i) = \setG(b(i),b(i+1))$. If $b$
is finite, then the sequence $r$ of pairs is one unit shorter than $b$. If
$b$ is infinite then $r$ is infinite.

We take the words \quotationMarks{trace}. The paper \cite{2001-SCT}
uses for the same concepts the word \quotationMarks{thread}. We use
\emph{path} for a finite or infinite path $f_0, f_1, f_2, \ldots$ 
in the graph define by $\setG$,
and \emph{multipath } for the image of a path under $\setG$:
$\setG(f_0, f_1), \setG(f_1, f_2), \ldots$ .
The paper \cite{2001-SCT} GTC, the Global Trace Condition,
as: \quotationMarks{all multipaths are in $DESC^\omega$}, 
where $DESC^\omega$ is the set of multipaths having some infinite descending thread.

We use \quotationMarks{thread}
and \quotationMarks{trace} as synonimous.
The terminology \quotationMarks{thread}
of cite{2001-SCT} is probably more suitable when speaking
of programs, while Brotherston and Simpson terminology,
\quotationMarks{trace}, appears more suitable when speaking of a 
proof-graph, as we do in this paper. 

We call value flow any assignment
of values in $\N$ to each $x \in X$, with the assignment 
depending on a time parameter $t$. We require that the the set of instants
of time is some non-empty initial segment of the set $\N$ of natural numbers,
possibly $\N$ itself.

We repeat the same definitions more formally.

\begin{definition}[Path, Trace and Value Flow]
Assume $\setR$, $\setG$ are as above.
Assume $D = [0,h]$ for some $h \in \N$ or $D=\N$ 
is any non-empty initial segment of the order on natural numbers.
\begin{enumerate}
\item
We call any map $b:D \rightarrow G$ a multipath, a \emph{path} for short
if and only if for all $i, i+1 \in D$ we have $(b(i),b(i+1)) \in \dom(\setG)$.
\item
We call any map $\tau:D \rightarrow X$ a \emph{trace} 
(called a \emph{thread} in \cite{2001-SCT}): 
a trace is any finite or infinite sequence over $X$.
\item
We call any map $\theta:D,X \rightarrow \N$ a \emph{value flow}. 
We call $\theta(t,x) \in \N$ the value of $x \in X$ at time $t \in D$.
\end{enumerate}
We say that a path, trace, value flow 
is finite when $D=[0,h]$ for some $h \in \N$, that it is infinite when $D = \N$.
\end{definition}



We are interested to a condition on $\setR, \setG$
called the \quotationMarks{Global Trace Condition} (GTC).
GTC is equivalent to the 
termination of value flows \quotationMarks{compatible}
with a path of $\setR, \setG$, as we will prove in Appendix.

GTC is expressed in term of traces.

\begin{definition}[Global Trace Condition (GTC) and Injectivity]
\label{definition-GTC-inj}
Assume $\setR, \setG$ are as above.
Suppose $X=\{x_1, \ldots, x_n\}$, $\setR =\{(\Stat_i, \Prog_i)| i \in [1,r]\}$
and $b, \tau$ are a path of $\setR, \setG$ and a trace, all of domain $D$ 
$D=[0,h]$ for some $h \in \N$ or $D=\N$.

\begin{enumerate}

\item
We say that the trace $\tau:D \rightarrow X$ is \emph{compatible} with the path
$b :D \rightarrow \setR$ on the same $D$, 
and we write $\tau \models b$, if and only if :
whenever $t, t+1 \in D$ and $\setG(b(t),b(t+1)) = (\Stat,\Prog) \in \setR$,
then the two consecutive values  of the trace are related by $\setR$, namely
 $\tau(t) (\Stat \cup \Prog) \tau(t+1)$.
If $\tau(t) \Prog \tau(t+1)$,
we say that $t \in D$ is a \emph{$b$-progress point} of the trace $\tau$.

\item
$\setR,\setG$ satisfy the \emph{Global Trace Condition} (GTC) if and only if
for all infinite paths $b$ in $\setR,\setG$
there is some infinite trace $\tau:\N \rightarrow X$ such that
$\tau \models b$ and $\tau$ has infinitely many $b$-progress points.

\item
We write $\universe{(\Stat, \Prog)}
= \Stat \cup \Prog$ for the \emph{union} of the pair $(\Stat, \Prog) \in \setR$.


\item
$\setR$ satisfies \emph{injectivity} if and only 
the union relation $\universe{(\Stat, \Prog)}$ is injective
for all $(\Stat, \Prog) \in \setR$.

\end{enumerate}

\end{definition}

When we have injectivity, we could remove the substruction 
\quotationMarks{$(\ldots) \setminus 
\Prog''$} in the definition of composition , because in this case if $\Stat,\Prog$ 
are disjoint and $\Stat', \Prog'$ are disjoint then  $\Stat \Stat'$ and $\Stat \Prog' \cup \Prog \Stat' \cup \Prog \Prog'$ are disjoint. In this case 
we have $(\Stat,\Prog)(\Stat',\Prog')=(\Stat'',\Prog'')$.

Again if we have injectivity, composition is
compatible with the union operator $\universe{\cdot}$ for relation pairs. 
Indeed we have
$$
\universe{(\Stat,\Prog)(\Stat',\Prog')} 
= 
\universe{
(\Stat \Stat', 
\Stat \Prog' \cup \Prog \Stat' \cup \Prog \Prog' \setminus \Stat \Stat')
}
=
\Stat \Stat' \cup (\Stat \Prog' \cup \Prog \Stat' \cup \Prog \Prog') 
\setminus \Stat \Stat'
=
$$
$$
=
\Stat \Stat' \cup \Stat \Prog' \cup \Prog \Stat' \cup \Prog \Prog'
=
(\Stat \cup \Prog) (\Stat' \cup \Prog') 
= 
\universe{(\Stat,\Prog)}\universe{(\Stat',\Prog')} 
$$
Lee and Ben-Aram considered in \cite{2009-Lee-Aram} the notion
of fan-in free for $\setR$, $\setG$. 
This notion is equivalent to our injectivity condition above 
(\ref{definition-GTC-inj}). However, the equivalence requires to
rename all sets $X$ in each node $f \in G$ to some set
$\Var(f)$, in order to make pairwise distinct the set of variables associated
to each node $f \in G$. We avoid renaming in this paper.

If formulated as above, the Global Trace condition (GTC) is equivalent to the criterion
for Size Change Termination (SCT), introduced by Neil Jones \cite{2001-SCT}. 
SCT was originally used as a sufficient, and quite broad too, 
condition for termination of recursive calls. 
When we use GTC as a correctness criterion for cyclic proofs,
\emph{we add one more condition, \underline{injectivity} of the trace relations}, 
a condition which is missing in the original SCT paper. 

Injectivity implies that in cyclic proofs two traces of different
variables never cross each other. This significantly simplifies traces.
Instead, in the original SCT formulation two traces, 
say, $x_1 \ge x_2 > x_3$ and
$y_1 > y_2$, from two different variables $x_1$, $y_1$,
can meet into a single variable $z$. For instance, we can have:
\begin{center}
$x_1 \ge x_2 > x_3 \ge z$ 
\ \ \ and \ \ \ 
$y_1 > y_2 \ge z$
\end{center}

In this paper we study GTC in the case $\setR$ is injective, and from a
purely combinatorial viewpoint, as a termination condition for value flows. 
Our result could also be used for checking termination of recursive calls, with a 
faster algorithm but unfortunately under less general conditions than in 
\cite{2001-SCT}. 
We hope that our result will be used for translating cyclic proofs into 
ordinary proofs, but for the moment we do not provide such translation.

We find a termination proof using Intuitionistic Logic, First 
Order Arithmetic and nested induction.

Several decidable equivalent are known for GTC. In Classical Logic, GTC for 
$\setR,\setG$ is equivalent to the fact that all value flows compatible 
with some path are finite: we postpone the proof to the Appendix.

We assume injectivity and we are looking for an equivalent version
of GTC which can expressed in First Order Aritmetic, and such that
the finiteness of all compatible value flows can be proved
in Intuitionistic Arithmetic.

We anticipate that when $n = \Card(X) \ge 1$, we will 
use lexicographic induction on a length $2n$ sequence 
$( m_1,r_1, \ldots, m_n,r_n)$.
For all $k \in [1,n]$, we will have $m_k \in \N \cup \{\infty\}$ and 
$r_k \in [0, \Card(G){n \choose k }[$, a finite initial segment of $\N$.

\subsection{The Size Change Termination condition (SCT)
and the Progressing Domain Condition (PDC)}
\label{subsection-SCT}
The SCT condition says:
\quotationMarks{
\emph{all self-composable relation pairs $(\Stat,\Prog)$
(i.e., such that $\composable{\setG}{a}{a}{(\Stat,\Prog)}$ for some $a \in G$)
have some finite power in which some $x \in X$ progresses to itself}
}. 
We can write SCT as follows:
$$
\forall (\Stat,\Prog) \in \setR, a \in G. 
\ (\composable{\setG}{a}{a}{(\Stat,\Prog)})
\ \implies \exists n \in \N \exists x \in X. 
\ (x \mbox{ progresses to $x$ in } (\Stat,\Prog)^n)
$$
In previous work we proved that the equivalence between SCT and GTC 
(already proved in \cite{2001-SCT}) is a corollary of Ramsey Theorem. 

In this paper we are looking for a more
constructive and elementary proof of an equivalent result, 
namely the termination
of all value flows compatible with some path of $\setR$.
The proof should be suitable to a formalization in a proof assistant.
We add the injectivity assumption because relation pairs with
injectivity are enough to describe cyclic proofs, and if we have injectivity
proving a termination result requires a weaker hypothesis PDC (see below). 
Besides, using PDC it is faster to check whether a cyclic proof is correct.

The Progressing Domain Condition (PDC) says: 
\quotationMarks{all self-progressing $(\Stat,\Prog) \in \setR^\setG$ 
have a progression from $x$ to $y$ with both elements 
included in the domain of $(\Stat,\Prog)$}, namely
$$
\forall (\Stat,\Prog) \in \setR, a \in G. 
\ \ (\composable{\setG}{a}{a}{(\Stat,\Prog)}) \implies \exists x, y \in \dom(\Stat\cup\Prog). 
\ (x \Prog y)
$$
PDC is weaker and it is easier to check than the SCT condition. 
To check PDC, we do not have to look for some $x$ progressing to itself in 
some power of any self-composable $(\Stat,\Prog)$. 
Instead it is enough to find some $x$ progressing 
to some $y$, such that both $x$, $y$ are in the domain of $\Stat \cup \Prog$,
again in any self-composable $(\Stat,\Prog) \in \setR^\setG$.

However, PDC has the drawback that it implies 
GTC and termination only for \emph{injective} relation pairs. 
We explain why.

\subsubsection{PDC does not imply GTC,
in the case of non injective family of relation pairs}
\label{subsubsection-counterexample-PDC-GTC}
Here is a counter-example $\setR_1,\setG_1$.
Let $X = \{x_1,x_2\}$, $\setR_1=\{(\Stat,\Prog)\}$, $G_1=\{1\}$
and $\Stat =\{(x_1,x_1)\}$, $\Prog =\{(x_2,x_1)\}$ and
$\setG_1(1,1) = (\Stat,\Prog)$, 
namely, the pair $(\Stat,\Prog)$ is self-composable. 
Then $\setR_1$ is composition-closed in $\setG$ because 
$
\Stat\Prog \cup \Prog\Prog \cup \Prog\Stat =
$ (by $\Stat\Prog = \Prog\Prog = \emptyset$) $
\Prog\Stat = 
\Prog
$
therefore
$
(\Stat,\Prog)(\Stat,\Prog) = 
(\Stat\Stat \setminus \Prog, \Prog) = 
(\Stat \setminus \Prog,\Prog) = 
(\Stat,\Prog)
$.
The unique pair $(\Stat,\Prog)$ satisfies PDC 
because $x_2 \in \dom((\Stat,\Prog))$
is progressing to  $x_1 \in \dom((\Stat,\Prog))$. However, $\setR_1$
does not satisfy GTC. Indeed, the unique infinite path in $\setR_1,\setG_1$ is 
$b = 1,1,1,\ldots$, labeled $(\Stat,\Prog),(\Stat,\Prog),(\Stat,\Prog),\ldots$.
Any infinite trace compatible with $b$ is either
$x_1 x_1 x_1 \ldots$ or $x_2 x_1 x_1 x_1 \ldots$. Thus, any infinite
trace compatible with $b$ progresses \emph{at most once}. 
The reason why the implication PDC $\implies$ GTC is false is because 
$\setR_1$ is not injective. Indeed, the relation 
$R = \universe{(\Stat,\Prog)} = \{(x_1,x_1), (x_2,x_1)\}$ is not injective,
$x_1$ and $x_2$ have the same image $x_1$.


Instead, we will prove that PDC+injectivity imply finiteness of value flows,
or, using Classical Logic, GTC:

\begin{theorem}[Finiteness of $\setR$-compatible transitions (weak form)]
\label{theorem-finiteness-value-flow-1}
If $\setR$ is any finite list of \emph{injective} relation pairs 
satisfying the Progressing Domain Condition (PDC)  in $\setG$
then any value flow compatible with $\setR,\setG$ is finite.
\end{theorem}

Assume $L:[1,l] \rightarrow \Pfin(\N \times \N)$

with $R_i = L(i)$ for all $i \in [1,l]$.
Then for all $i,j \in [1,l]$, $i \le j$ we define
$R_{i,j} = \Pi_{h=i}^{h=j} R_j = R_i \ldots R_j$.

By Lemma \ref{lemma-composition-injective-relations-01} 
and $\dom(R_{i,j+1}) = \dom(R_{i,j} R_{j+1})$ we have
$\dom(R_{i,j})  \supseteq \dom(R_{i,j+1})$, that is,
the sequence of sets $\dom(R_{i,j})$
for $j \in [i,l]$ is weakly decreasing w.r.t. inclusion. Thus, the sequence 
$\{\Card(\dom(R_{i,j})) | j \in [i,l]\}$ is weakly decreasing w.r.t. the ordering on $\N$.
When for each $i \in [1,l]$  the sequence $\{\Card(\dom(R_{i,j})) | j \in [i,l]\}$ 
is constant we say that the list $L$ has \emph{stable-cardinality} domains. 
When all cardinalities are $\Card(\dom(R_{i,j}))$ are the same we
say that $L$ has constant-cardinality domains.

Here is the formal definition.

\begin{definition}
[Stable-Cardinality Domain for a sequence on $\setR$]
Assume $L:[1,l] \rightarrow \Pfin(X \times X)$
is a finite relation sequence and
$\pi:[1,l] \rightarrow \Pfin(X \times X)^2$ is
a finite sequence of pairs of finite relations on $X$.

\begin{enumerate}

\item
$L$ has \emph{stable-cardinality domains} if and only if all $i \in [1,l]$ 
we have $\Card(\dom(R_i)) = \Card(\dom(R_{i,l}))$.

\item
$L$ has \emph{constant cardinality domains} if and only if all 
$i,j \in [1,l]$, $i \le j$ 
we have $\Card(\dom(R_{i,j})) = \Card(\dom(R_{1,l}))$.

\item 
$\pi$ has \emph{stable-cardinality domains} 
(respectively, has \emph{constant cardinality domains})
if and only if the associated relation sequence 
$\{\universe{\pi(i)} | i \in [1,l]\}$, obtained by taking the union
of each pair $\pi(i) = (\Stat_i,\Prog_i) \in \setR$, has stable-cardinality domains 
(respectively, has constant cardinality domains).

\item
$\pi$ has \emph{non-progressing domains} if and only if for all 
$i, j \in [1,l]$, $i < j$ we have $\neg (x \Prog_{i,j} y)$ for all 
$x \in \dom(\pi(i))$, $y \in \dom(\pi(j))$.
\end{enumerate}

\end{definition}

\section{Appendix: PDC, GTC and SCT are Equivalent Given Injectivity}
The goal of this section is to compare PDC with the GTC with and 
without injectivity. 
We Claim:
\begin{enumerate}
\item
\label{property-1}
SCT, GTC are equivalent with PDC given injectivity:
$$
\forall \setR, \setG.  \ \ 
(\setR \mbox{ injective}) 
\implies 
(SCT \Leftrightarrow PDC) \wedge 
(GTC \Leftrightarrow PDC)
$$
\item
\label{property-2}
Instead, in general we only have left-to-rigth implication
$$
\forall \setR, \setG.  \ \ 
(SCT \Rightarrow PDC) \wedge 
(GTC \Rightarrow PDC)
$$
\item
\label{property-3}
while the opposite implication can fail:
$$
\exists \setR, \setG. \ \ 
\neg(\setR \mbox{ injective}) \wedge 
\neg SCT \wedge 
\neg GTC \wedge 
PDC
$$
\end{enumerate}

Point \ref{property-3} of the Claim
was already proved with the counter-example $\setR_2$
in \S \ \ref{subsubsection-counterexample-PDC-GTC}.

The implication GTC $\Rightarrow$ PDC follows from the fact that
for all self-composable $\composable{\setG}{a}{a}{(\Stat,\Prog)}$ 
there is some path $\pi = a,a,a,a,\ldots$ labeled $R,R,R,R,...$,
where $R = \universe{(\Stat,\Prog)} = \Stat \cup \Prog$. By GTC,
there is some infinitely progressing trace $z_1,z_2,z_3,\ldots$ in $\pi$.  
In any progressing point $i$ of the trace we have $z_i \Prog z_{i+1}$
and $z_{i+1} R z_{i+2}$. We conclude that $z_i \Prog z_{i+1}$
and $z_i, z_{i+1} \in \dom(R)$ for some $z_i, z_{i+1}$, that is,
PDC for the self-composable pair $(\Stat,\Prog)$.
\\

In order to prove SCT $\Rightarrow$ PDC, we recall 
that Neil Jones in \cite{2001-SCT} 
proved the equivalence of the conditions called in this paper 
SCT (\S \ref{subsection-SCT}) and GTC
$$
\forall \setR, \setG.  \ \ 
(SCT \Leftrightarrow GTC)
$$
Thus, from GTC $\Rightarrow$ PDC just proved we deduce SCT $\Rightarrow$ PDC. 
We proved one direction, namely point \label{property-2} of the Claim.
\\

Now we prove the other direction, namely point \label{property-1} of the Claim.
It is enough to prove that if $\setR$ is injective then PCD $\Rightarrow$ SCT. If will follow
if $\setR$ is injective then PDC $\Rightarrow$ GTC. 

We first prove a property of injective transitive relation: this property does not
involve coloring, nor the fact that the relation is finite.

\begin{proposition}[Transitive Injective Relations]
\label{proposition-transitive-injective}
Assume $X$ is any set and $R \subseteq X \times X$ is any binary relation.
\begin{enumerate}
\item
\label{proposition-transitive-injective-01}
If $R$ is transitive and $R$ is injective, then any two elements of $\dom(R)$ related by $R$ 
are equal, namely $R \restr \dom(R) \subseteq \id_{\dom(R)}$.
\item
\label{proposition-transitive-injective-02}
If $R=RR$ and $R$ is injective, then two elements of $\dom(R)$ are related by $R$ 
\emph{if and only if} they are equal, namely $R \restr \dom(R) = \id_{\dom(R)}$.
\end{enumerate}
\end{proposition} 

\begin{proof}
\begin{enumerate}
\item
%\label{proposition-transitive-injective-01}
Assume $x, y \in \dom(R)$ and $x R y$ in order to prove $x = y$. 
From $y \in \dom(R)$ we deduce that for some
$z \in X$ we have $y R z$. By transitivity of $R$ we have $x R z$. By $y R z$ and injectivity
we conclude that $x = y$, as wished.

\item
%\label{proposition-transitive-injective-02}
Assume $x, y \in \dom(R)$ in order to prove $x = y$ if and only if $x R y$. By $R=RR$
we deduce that $R$ is transitive, and by point \ref{proposition-transitive-injective-01} above,
that $x R y$ implies $x=y$. Now we assume $x=y$ in order to prove $x R y$. 
From $x \in \dom(R)$ we deduce $x R z$ for some $z \in X$. From $R =RR$ we deduce
that for some $v \in X$ we have $x R v$ and $v R z$. From $x R z$, $v R z$ and injectivity
we obtain $x = v$. From $x R v$ and $x = y$ we conclude that $x R y$,
as wished.
\end{enumerate}
\end{proof}

We now prove that all \emph{finite} relations have some positive power which is idempotent.

\begin{proposition}
\label{proposition-idempotent-power}
Assume $X$ is any finite set and $R \subseteq X \times X$ is any finite binary relation.
Then for some $n>0$ we have $R^n=R^nR^n$.
\end{proposition}

\begin{proof}
Since $R$ is finite, there are only finitely many powers of $R$, therefore 
for some $a,b>0$ we have $R^a = R^{a+b}$. Then for all $c \ge a$ we have $R^c = R^{c+b}$,
hence $R^c = R^{c+db}$ for all $d>0$. Take the first $d>0$ such that $db \ge a$: then 
$R^{db} = R^{db+db}$. We take $n=db$.\footnote{There is an alternative proof using
Finite Ramsey Theorem. We take the complete graph on $\N$, and we color the 
edge between $i$ and any $j>i$ with $R^{j-i}$. There are finitely many colors.
By Finite Ramsey Theorem there is a monocromatic set with $3$ elements $i<j<k$. 
If the color of the set is $R^m$, then the edge between $i$ and $j$ and between $j$ and $k$
is $R^m$. By definition of coloring, the edge between $i$ and $k$ is $R^mR^m$, 
by Ramsey Theorem it is $R^m$. We conclude that $R^m = R^mR^m$. }
\end{proof}

We can now prove that if we have injectivity then PDC $\Rightarrow$ SCT.

\begin{theorem}
Assume $X$ is any finite set and $\setR \subseteq X \times X$ is any composition-closed
finite family of finite bi-colored \emph{injective} binary relations. If $\setR$ satisfies PDC and 
is \emph{injective} then $\setR$ satisfies SCT.
\end{theorem}


\begin{proof}
Assume that $(S,P) \in \setR$ is some bi-colored finite relation on $X$,
in order to prove that for some $n \in \N$, $n>0$, for $(S_n,P_n) = (S,P)^n$ there is some
$x \in X$ such that $x P_n x$. 

Let $R = \universe{(S,P)} = S \cup P$. $R$ is finite, therefore by Prop. 
\ref{proposition-idempotent-power} for some $n \in \N$ we have $R^n = R^nR^n$. 
In particular, $R^n$ is transitive. 
We have $R^n = \universe{(S,P)}^n = \universe{(S,P)^n}$. By composition-closure of 
$\setR$ we deduce  $(S,P)^n \in \setR$, hence $R^n$ is injective and $(S,P)^n$ satisfies PDC. 
Thus, there are $x, y \in \dom(\universe{(S,P)^n}) = \dom(R^n)$ such that $x P_n y$, 
hence $x R^n y$. By proposition 
\ref{proposition-transitive-injective}.\ref{proposition-transitive-injective-01} 
we obtain that $x = y$. We conclude that $x P_n x$, as wished.
\end{proof}

the \emph{injective self-composable idempotent relations $R$} are the identity relation when

$R$ is a finite relation on a finite set $X$, therefore by Prop.

\item
We have to prove that \emph{$R \restr \dom(R) $ is a bijection}. 
Let $\dom(R) = \{y_1, \ldots, y_m\}$. Assume
$i \in [1,m]$, $y_i \in \dom(R)$: 
from $R=RR$ we deduce that $y_i \in \dom(RR)$, therefore
there are $(y_i,y) \in R$ and $(y,z) \in R$. From $(y,z) \in R$ 
we obtain $y \in \dom(R)$. 
Let $C_i = \{y \in \dom(R) |(y_i,y) \in R\}$ and $c_i = \Card(C_i)$. 
By $y_i \in \dom(R)$ 
we have $c_i \ge 1$, hence $\Sigma_{i \in [1,m]} c_i \ge m$. 
By injectivity of $R$ if  $C_i \cap C_j \not = \emptyset$ then $i=j$, therefore 
$\{C_i | i \in [1,m]\}$ are a partition of some subset of $\dom(R)$
and we have $\Sigma_{i \in [1,m]} c_i \le m$. 
We deduce that $\Sigma_{i \in [1,m]} c_i  = m$,
and from it that $c_i=1$ for all $i \in [1,m]$. Thus, 
$R \restr \dom(R) $ is an injection on a finite set $\dom(R)$.
By the characterization of bijections on finite sets we 
conclude that $R \restr \dom(R) $ is a bijection.

\item
In the point above we proved that $R \restr \dom(R) $ is 
a bijection and we have to prove that \emph{it is an identity}. Any bijection
of the finite set $\dom(R)$ is an union of pairwise disjoint cycles of the form 
$D = \{z_1, \ldots, z_p\}$ for some $p \ge 1$. We have $z_i R z_j$
if and only if $j = i+1 \mod p$ and we have
$z_i RR z_j$ if and only if $j = i+2 \mod p$.
From $R=RR$ and $z_1 R z_2$ we deduce $z_1 RR z_2$, then by choosing
$i=1$, $j=2$ that $2=1+2 \mod p$, and eventually that $0=1 \mod p$. 
We conclude that $p=1$. Thus, all cycles in
$R \restr \dom(R) $ are unary and therefore
$R \restr \dom(R) $ is the identity.

We prove that \emph{for all $x \in \dom(R)$, $x$ is progressing or 
weakly progressing to itself}.
From $R \restr \dom(R)$ identity (the previous point)
we deduce that $x R x$, either $x$ is progressing to $x$ or 
$x$ is weakly progressing to $x$.

\item
We prove that \emph{for some $x \in \dom(R)$, $x$ is progressing to itself}.
By PDC there are some $y, z \in \dom(R)$ such that $y$ is progressing to $z$.
By the previous point $R \restr \dom(R) $ is an identity.
We deduce that $y=z$. Thus, some $y \in \dom(R)$ is progressing to itself.

\end{enumerate}
\end{proof}

By Prop. \ref{proposition-idempotent-power} for all finite relations $R$ 
there is $m \in \N$, $m \ge 1$ such that $R^m = R^m R^m$. By the previous
Lemma, if $\setR$ is injective, $(\Stat,\Prog) \in \setR$ is self-composable  in $\setG$, 
we deduce that some $x$ in progressing to itself 
in $(\Stat,\Prog)^m$. This proves SCT, hence GTC.
\\




\section{Appendix: Comparing Global Trace Condition (GTC) 
with Termination of Computations (TC)}
In this section we prove that the Global Trace Condition is equivalent to
the termination of all computation flows, from now on, just TC for short.

We recall that a computation flow is some sequence 
$((a_1,(\Stat_1,\Prog_1),a_2),\sigma_1)$,
$((a_2,(\Stat_2,\Prog_2),a_3),\sigma_2), \ \ldots$ of states, such that
$$\composable{\setG}{a_1}{a_2}{(\Stat_1,\Prog_1)}, \ \ \ 
\composable{\setG}{a_2}{a_3}{(\Stat_2,\Prog_2)}, \ldots$$ and
for all $x, y \in X$, whenever $x \Stat_i y$ then $\sigma_i(x) \ge \sigma_{i+1}(y)$,
whenever $x \Prog_i y$ then $\sigma_i(x) > \sigma_{i+1}(y)$.

\begin{definition}[TC]
TC is short for: all possible computation flows terminate.
\end{definition}

Using Classical Logic, 
it is immediate that GTC $\implies$ TC. Indeed, in any infinite computation 
flow there is some variable $x \in X$ with some infinitely progressig trace. 
This implies that the value of $x$ is infinitely decreasing in the domain $\N$,
and this cannot be. 


The converse TC $\implies$ GTC is true but not immediate. Using Classical 
Logic, we prove it in the form $\neg$ GTC $\implies$ $\neg$ TC. Actually
we prove a stronger result: if GTC is false, there is some \emph{constant}
infinite transition $s, s, s, \ldots$ for some $s = (\Stat,\Prog),\sigma) \in \setS$,
in particular Termination of Computations (TC) fails. In this infinite
transition all traces progresses at most $n-1$ times, with $n=\Card(X)$.

\begin{proof}[Proof of $\neg$ GTC $\implies$ $\neg$ TC]
Assume $\neg$ GTC. By Theorem 4, \cite{2001-SCT} 
we deduce $\neg$ SCT, namely
that there is some self-composable 
$(a,(\Stat,\Prog),a) \in \setR$ such that for no $m \in \N$, $m>0$, 
$x \in X$ we have $x$ progressing to itself in $(\Stat,\Prog)^m$.

We define $s = ((\Stat,\Prog),\sigma) \in \setS$, then 
some \emph{constant}infinite transition $\theta = (s, s, s, \ldots)$.

We say that a trace $\tau:[1,t] \rightarrow X$ 
is irredundant if and only if all its elements are 
pairwise distinct, namely: $\forall i,j \in [1,t]. \tau(i) = \tau(j) \implies i=j$. 
An irredundant trace has at most $n$ elements, where  $n = \Card(X)$, and
progresses at most $n-1$ times, because the last element of the trace
does not progress, having no next element.
\\

Let $\pi = (\Stat,\Prog), (\Stat,\Prog), \ldots$
be the infinite constant path repeating the self-composable pair $(\Stat,\Prog)$.
We set $\sigma(x)=$ the maximum number of progressions in
an irredundant trace $\tau$, starting
 from $x$ and compatible with $\pi$. The maximum
exists because an irredundant trace has at most $n$ elements,
therefore there are finitely many irredundant traces from $x$. In fact,
we also know that $\sigma(x) \le n-1$.
\\

Now we prove that $\theta = (s, s, s, \ldots)$ is a constant infinite transition.
We have to prove that for all $x,y \in X$ if $x \Stat y$ then $\sigma(x) \ge
\sigma(y)$ and if $x \Prog y$ then $\sigma(x) >
\sigma(y)$, namely $\sigma(x) \ge \sigma(y)+1$. 
Assume $\sigma(x) = a$ and $\sigma(y) = b$.  
By definition of $\sigma$ there is some irredundant trace $\tau$ from $y$ 
whose progressing points in $\pi$ are in number of $b$. 
We have to prove that $\sigma$ is compatible with $(\Stat,\Prog)$,
namely that $a \ge b$ if $x \Stat y$ and $a \ge b+1$ if $x \Prog y$.
\\

For, we define a trace $\rho = (x) \conc \tau$.
$\rho$ could be not irredundant, however we can repeatedly replace each
cycle included in $\rho$ with its first element. 
Each time we obtain a shorter trace from $x$, eventually we obtain an irredundant
trace $\rho'$. All the cycles we removed are not progressing,
otherwise there would be some power of $(\Stat,\Prog)$ and some $z \in X$
 progressing to itself. Therefore whenever we remove a cycle from$\rho$
 we preserve the number of progressions. This number is $b$ if $x \Stat y$
 and is $b+1$ if $x \Prog y$. By definition of $\sigma(x) = a$ we deduce
 $a \ge b$ if $x \Stat y$ and $a \ge b+1$ if $x \Prog y$, as wished.
\end{proof}

Remark that in fact we proved a stronger property: either we have SCT and
GTC and TC, or we have $\neg$ SCT and $\neg$ GTC and $\neg$ TC. In the
second case we also have an infinite constant transition $\theta = (s, s, s, \ldots)$
in which all traces progresses at most $n-1$ times, with $n=\Card(X)$.
