\section{Cyclic Proofs and the Global Trace Condition}
\label{sec:cyclic}

In this section, we define the GTC, for the cyclic proof systems $\CLKIDomega$ and $\CLJIDomega$. The difference with the previous formulation is that we consider an injective trace relation, as we will see.

$\CLKIDomega$ and $\CLJIDomega$ are both systems for first-order theories, hence we consider a signature $\Sigma$, which contains symbols for constants, functions, and predicates of individuals. Terms, formulas, and $\Sigma$-structures are defined as usual. We consider sequents as originally defined by Gentzen using finite lists, instead of the formulations in \cite{Brotherston2, BrotherstonSimpson} using sets or multisets. 

In the case of $\CLKIDomega$, sequents have the form $\Gamma \vdash \Delta$, while in $\CLJIDomega$, they are defined as $\Gamma \vdash \phi$, where $\Gamma$ and $\Delta$ are finite lists of formulas, and $\phi$ is either a single formula or the empty list. 
The comma between lists of formulas (e.g. $\Gamma, \Delta$) denotes list concatenation. For any formula $F$ in a list $\Gamma$, we define the \emph{occurrence} of $F$ in $\Gamma$ as the formula $F$ paired with the position $i$ where it appears in $\Gamma$, written as $(F,i)$. Predicate symbols are divided between \emph{inductive predicates}, as in Martin-Löfs \emph{productions} \cite{MartinLof}, and \emph{ordinary predicates}. To formally define inductive predicates, we introduce the notion of \emph{inductive definition set}.

\begin{definition}[Inductive definition set]
    \label{defIndSet}
    An inductive definition set $\Phi$ is a finite set of \emph{productions} $r$ of the form:

    \begin{center}
        \centering
        \begin{prooftree}
            \hypo{Q_1\mathbf{u_1} \ldots Q_h\mathbf{u_h}}
            \hypo{P_1\mathbf{t_1} \ldots P_m\mathbf{t_m}}
            \infer2[r]{P\mathbf{t}}
        \end{prooftree}
    \end{center}

\noindent
where $Q_1, \ldots, Q_h$ are ordinary predicates symbols, $P_1, \ldots, P_m$ are inductive predicate symbols, and $\mathbf{u_1}, \ldots, \mathbf{u_h}$, $\mathbf{t_1}, \ldots, \mathbf{t_m}$, $\mathbf{t}$ are tuples of terms.

A production of conclusion $P \mathbf{t}$ for some $\mathbf{t}$ is said to be a production for $P$. A formula is said \emph{inductive} when it is an atomic formula $P\mathbf{t}$ for some inductive predicate $P$ and some $\mathbf{t}$.
\end{definition}

We define the proof system $\CLKIDomega$ for inductive predicates as an extension of the classical logic LK, whose rules are reported in Figure \ref{LKrules}, with additional rules used to handle inductive predicates on the right and left part of the sequent. These rules for inductive predicates are defined as follows: let $\Phi = \{r_1, \ldots, r_n\}$ be the inductive definition set, such that all $r_i$ are productions as in Definition \ref{defIndSet}.

\begin{itemize}
    \item For each production $r_i$ for an inductive predicate $P$, the system $\CLKIDomega$ includes a corresponding right introduction rule for $P$, denoted ($P\text{R}_i$):

    \label{def:caseRuleRight}

        \hypo{\vnode7{\Gamma} \vdash \vnode8{P_1\mathbf{t_1}}, \vnode9{\Delta} \ldots \vnode{10}{\Gamma} \vdash \vnode{11}{P_m\mathbf{t_m}}, \vnode{12}{\Delta}}
        \infer2[($P\text{R}_i$)]{\vnode{13}{\Gamma} \vdash \vnode{14}{P\mathbf{t}}, \vnode{15}{\Delta}}
    \end{prooftree}
    %ARROWS
    %----------------------------------

    %\bentdirflowrededges{node14/node2/25, node14/node5/0, node14/node8/0, node14/node11/-25} 
    $

    \end{equation}

    \item For all inductive predicates $P$ there is a \emph{single} left introduction rule associated to $P$ and to all productions $r_i  \in \Phi$ for $P$. It is denoted \emph{case split rule for $P$} or (Case $P$):
    
    \begin{equation}
    \label{def:caseRuleLeft}
    \begin{prooftree}
        \hypo{ \{ \vnode1{\Gamma}, \vnode{11}{\mathbf{u} = \mathbf{t^i}}, \vnode3{Q^i_1\mathbf{u^i_1}}, \ldots , \vnode4{Q^i_h\mathbf{u^i_h}}, \vnode5{P^i_1\mathbf{t^i_1}}, \ldots, \vnode6{P^i_m\mathbf{t^i_m}} \vdash \vnode7{\Delta} \}_{1 \leq i \leq n} }
        \infer1[$(Case P)$]{\vnode8{\Gamma}, \vnode9{P\mathbf{u}} \vdash \vnode0{\Delta}}
    \end{prooftree}
    %ARROWS
    %----------------------------------

    \bentdirflowblueedges{node8/node1/20}
    \bentdirflowrededges{node9/node5/0, node9/node6/0}

    In the rule (Case $P$),for each production $r_i$, there is a corresponding sequent in the premises of the form $\Gamma, \mathbf{u} = \mathbf{t^i}, Q^i_1\mathbf{u^i_1}, \ldots , Q^i_h\mathbf{u^i_h}, P^i_1\mathbf{t^i_1}, \ldots, P^i_m\mathbf{t^i_m} \vdash \Delta$ subject to the restriction that any free variable in $\mathbf{u^i_1},...,\mathbf{u^i_h},\mathbf{t^i_1},...,\mathbf{t^i_m}$, or $\mathbf{t^i}$, does not occur free in $\Gamma, \Delta$ and $\mathbf{u}$.

\end{itemize}

To the usual presentation of these rules, we add a \emph{trace relation} among occurrences of inductive formulas, which is represented by {\color{blue} \bf blue} and {\color{red} \bf red} arrows from the conclusion to the premises, according to the clauses below and Definition \ref{def:subOccur}. 


\begin{enumerate}[i)]
    \item Arrows of either color connect occurrences $(P\mathbf{u}, i)$ on the left side of the conclusion's sequent, to occurrences $(Q\mathbf{t}, j)$ on the left side of the premises' sequents of each rule, where $P$ and $Q$ are inductive predicates.
    \item The {\color{blue} \bf blue} arrow from a list $\Gamma$ in the conclusion to the same list $\Gamma$ in a premise \emph{defines a bijection} between occurrences $(P\mathbf{u},i)$ in the list $\Gamma$ in the conclusion, and $(P\mathbf{u},i)$ in the \emph{same position} of the list $\Gamma$ in the premise.
    \item The {\color{blue} \bf blue} arrow from a list $\Gamma[\theta]$ in the conclusion to $\Gamma$ in a premise, in the rule $(Subst)$, defines a bijection between occurrences $(P\mathbf{u}[\theta],i)$ in the list $\Gamma[\theta]$ in the conclusion, and $(P\mathbf{u},i)$ in the list $\Gamma$ in the premise.
    \item The {\color{blue} \bf blue} arrow from a list $\Gamma[t/x,u/y]$ in the conclusion to $\Gamma[u/x,t/y]$ in a premise, in the rule (=L), defines a bijection between occurrences $(P\mathbf{u}[t/x,u/y],i)$ in the list $\Gamma[t/x,u/y]$ in the conclusion, and $(P\mathbf{u}[u/x,t/y],i)$ in the list $\Gamma[u/x,t/y]$ in the premise.   
\end{enumerate}


\begin{definition}[Trace Relation]
    \label{def:subOccur}
    Let $r$ be a rule in $\CLKIDomega$, with conclusion $\Gamma \vdash \Delta$ and premises $\Gamma_1 \vdash \Delta_1, \ldots, \Gamma_n \vdash \Delta_n$. Moreover, consider the ocurrences $(P\mathbf{u},i)$ in $\Gamma$ and $(Q\mathbf{t},j)$ in $\Gamma_k$ for some $ 1 \leq k \leq n$, where $P$ and $Q$ are inductive predicates. We say that $(P\mathbf{u},i)$ is connected to $(Q\mathbf{t},j)$ in $r$, noted $(P\mathbf{u},i) \rightarrow_{r} (Q\mathbf{t},j)$ if and only if there is an arrow drawn from $(P\mathbf{u},i)$ to $(Q\mathbf{t},j)$ in the definition of rule $r$ in the Figure \ref{LKrules} or the Formulas (\ref{def:caseRuleRight}) and (\ref{def:caseRuleLeft}). $(P\mathbf{u},i)$ is called a \emph{progressing} occurrence, if only {\color{red} \bf red} arrows originate from it, and a \emph{stationary} occurrence if all arrows out of it are {\color{blue} \bf blue}.
\end{definition}

The intended meaning of {\color{red} \bf red} progressing arrows and of {\color{blue} \bf blue} stationary arrows is: when $P\mathbf{t}$ progresses to $Q\mathbf{u}$ then the vector denoted by $\mathbf{t}$ has larger size than the vector denoted by $\mathbf{u}$, when there is a stationary connection then $\mathbf{t}$ and $\mathbf{u}$ denote the same vector.

The proof system for $\CLJIDomega$ and its trace relation is naturally obtained by restricting the rules for inductive predicates over intuitionistic sequents, preserving the exchange rule, and replacing LK with its intuitionistic version, named LJ (see, for instance \cite{Berardi}). 

Our presentation differs from the previous one in that we consider an \emph{injective} trace
relation, as the next Proposition says.

\newcommand{\codom} {{\tt cod}}

\begin{proposition}
\label{prop:injective-trace}
\begin{enumerate}
\item
\label{prop:injective-trace-01}
Assume ${\mathcal R} = \{R_i | i \in I\}$ is a set of injective relations on $X \times Y$
such that $(\exists x \in \codom(R_i) \cap \codom(R_j)) \implies i=j$.
Then $\cup {\mathcal R}$ is an injective relation on $X \times Y$. 
\item
\label{prop:injective-trace-02}
The trace relation we defined is injective.
\end{enumerate}
\end{proposition}

\begin{proof}
\begin{enumerate}
\item
%\label{prop:injective-trace-01}
Let $R = \cup {\mathcal R}$. Assume $x R y$ and $x' R y$ in order to prove that
$x = x'$. From $x R y$ and $x' R y$ we deduce
$x R_i y$ and $x' R_j y$ for some $i,j \in I$. From $y \in \codom(R_i) \cap \codom(R_j)$
we deduce that $i = j$, therefore $x R_i y$ and $x' R_i y$. 
From $R_i$ injective we conclude that $x = x'$.
\item
%\label{prop:injective-trace-02}
For all rules we considered a trace relation union of injective relations 
on sequents and on single formulas which are injective and have \emph{disjoint codomain}. 
By point \ref{prop:injective-trace-01} above, these unions define an injective trace relation.
\end{enumerate}
\end{proof}

\emph{Cyclic pre-proofs}, defined below, are used to formally represent a \emph{possibly infinite regular 
derivation} in $\CLKIDomega$ and $\CLJIDomega$ through a \emph{finite graph}.

\begin{definition}[Cyclic pre-proof] A $\CLKIDomega$ (resp. $\CLJIDomega$) pre-proof of sequent $\Gamma \vdash \Delta$ (resp. $\Gamma \vdash \phi$), is a tuple $\Pi = (\mathcal{D}, \mathcal{F})$, where:

    \begin{itemize}
        \item $\mathcal{D} = (V, s, r, p)$ is a derivation tree where $V$ is a finite set of vertices, $s: V \rightarrow Seqs$ is a total function labelling vertices with sequents in $\CLKIDomega$ (resp. $\CLJIDomega$), $r: V \rightarrow Rules$ is a partial function labelling vertices with inference rules in $\CLKIDomega$ (resp. $\CLJIDomega$), $p: \mathbb{N} \times V \rightarrow V$ is a partial function that maps a number $n$ and a vertex $v$, with a vertex $v'$, such that $v'$ is labeled by the $n^{\text{th}}$ premise of the rule $r(v)$ over the sequent $s(v)$, and for every $v \in V$, 
            \begin{prooftree}
                \hypo{s(p_1(v)) \quad \dots \quad  s(p_m(v))}
                \infer1[$(r(v))$]{ s(v)}
            \end{prooftree} 
        is an instance of the rule $r(v)$ in $\CLKIDomega$ (resp. $\CLJIDomega$), with $m$ premises. A vertex $B \in V$ such that $r(B)$ is undefined is called a bud node. The set of bud nodes of a derivation tree $\mathcal{D}$, is written as $Bud(\mathcal{D})$.

        \item $\mathcal{F}: V \rightarrow V$ is a partial function, that maps each one of the bud nodes in $Bud(\mathcal{D})$ to an internal node in the derivation tree, called a companion, satisfying that if $B \in Bud(\mathcal{D})$ and $\mathcal{F}(B) = C$, then $r(C)$ is defined and $s(B) = s(C)$.
    \end{itemize}

Moreover, the graph of $\Pi$, written as $G_{\Pi}$, is the graph obtained after adding the edges induced by $\mathcal{F}$ and deleting the bud vertices. Specifically, $G_{\Pi} = (V', s, r, p')$ where, $V' = V \setminus Bud(\mathcal{D})$ and $p'$ is defined for any $j$ as: $p'_j(v) = \mathcal{F}(p_j(v))$ if $p_j(v) \in Bud(\mathcal{D})$, or $p'_j(v) = p_j(v)$ otherwise.
\end{definition}

As mentioned before, the Global Trace Condition (GTC) is used as a sufficient criterion to verify the soundness of cyclic pre-proofs in $\CLKIDomega$ and $\CLJIDomega$. To define it, it is first necessary to formalize both the notions of \emph{trace} and \emph{progress point}. 

\begin{definition}[Trace and Progress Point]
    \label{def:traceCyclic}
    Let $\Pi$ be a $\CLKIDomega$ (resp. $\CLJIDomega$) pre-proof and let $(v_i)$ be a sequence of vertices defining a path in $G_{\Pi}$. A trace over $(v_i)$ is a sequence of occurrences $\uptau$ such that, for all $i$:

    \begin{itemize}
          \item $\uptau(i) = (P\mathbf{u},j)$ is in $\Gamma$, where $P$ is an inductive predicate, and $s(v_i) = \Gamma \vdash \Delta$ (resp. $s(v_i) = \Gamma \vdash \phi$).

          \item If $\uptau(i) = (P\mathbf{u},j)$, then $\uptau(i+1) = (Q\mathbf{t},k)$, where $(Q\mathbf{t},k)$ is an occurrence such that $Q$ is an inductive predicate, $(P\mathbf{u},j) \rightarrow_{r(v_i)} (Q\mathbf{t},k)$, and $(Q\mathbf{t},k)$ is in $\Gamma'$, where $s(v_{i+1}) = \Gamma' \vdash \Delta'$ (resp. $s(v_{i+1}) = \Gamma' \vdash \phi'$).

          \item If $r(v_i) = (\text{Case } P)$ is a case split rule, and $\uptau(i) = (P\mathbf{u},j)$ is the progressing occurrence of the rule, then $i$ is said to be a progress point of the trace.
          \item A trace is infinitely progressing if it has infinitely many progress points.
    \end{itemize}  

\end{definition}

\begin{remark}
    \label{rem:traceDef}
    The previous definition of trace corresponds to a proper subset of the original trace definition by Brotherston in \cite[Definition 4.2.3]{Brotherston1}. Specifically, our definition of trace corresponds to applying Brotherston's definition to work over occurrences instead of formulas. The reason we use occurrences, is that they allow us to track the essential part of the history of a formula in a pre-proof without ambiguities, and it ensures that two distinct arrows of the trace relation, will never join in the same occurrence of a premise, which will be exploited in Section \ref{sec:progressDomainCond}.
\end{remark}  

We now define the validity condition for pre-proofs, which we call the global trace condition, following the literature.

\begin{definition}[Global Trace Condition]
    \label{def:GTC}
    A $\CLKIDomega$ (resp. $\CLJIDomega$) pre-proof $\Pi$ is said to be a $\CLKIDomega$ (resp. $\CLJIDomega$) \emph{proof}, if for every infinite path in $G_{\Pi}$, there is an infinitely progressing trace following some tail of the path.
\end{definition}

\begin{example}
    Consider the cyclic pre-proof in Figure \ref{exampleCircProof} and the only infinite path, contained in the cycle between the two right-most branches of the pre-proof. The trace $\uptau = (Ox, Ey, Ey, Ey, Ex, Oy, Oy, Oy, Ox)^{\omega}$  is infinitely progressing over this path, since it contains the progressing points $(Ox,Ey)$ and $(Ex,Oy)$. Since this is the only infinite path in the pre-proof, we say that it satisfies the GTC, and it is a $\CLKIDomega$ proof.
\end{example}
