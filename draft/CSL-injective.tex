\section{Global Trace Condition and Injective Relations}
\label{sec:injective}

We define the injective bi-partite relations and argue that they suffice for the GTC in the case of the cyclic
systems $\CLJIDomega$ and $\CLKIDomega$.
\medskip

\subsection{The Global Trace Condition}
\label{subsec:GTC}

\begin{definition}[Trace, path and progress]\label{def:TracePath}
Let $\alpha \leq \omega$ be an ordinal, and $\Graph = (V, \biRel, E)$ a transition graph; then:
\begin{enumerate}[i)]
\item a {\em trace} is a map $\tau:\alpha \to X$;
\item a {\em path} is a map $\ppath:\alpha \to E$ such that for all $i + 1 < \alpha$, $\target{\ppath(i)} = \source{\ppath(i+1)}$;
\item a trace $\tau$ is {\em compatible} with a path $\ppath$ (with the same domain $\alpha$), written $\tau \models \ppath$, if 
	there is $i_0 < \alpha$ such that for all $i_0 \leq i < i+1 < \alpha$,
	if $\lbl{\ppath(i)} = (S,P)$ then $\tau(i) (S \cup P) \tau(i + 1)$, and if $\tau(i) P \tau(i + 1)$ then $i$
	is a {\em progress point} of $\tau$ in $\ppath$.
\end{enumerate}
\end{definition}

A trace $\tau:\alpha \to X$, respectively a path $\ppath:\alpha \to E$ are infinite if $\alpha = \omega$, finite otherwise.
We say that $\tau$ is a trace of $\Graph$ if $\tau \models \ppath$ for some path $\ppath$ of $\Graph$. 

%If $\tau \models\ppath$ in $\Graph$
%and $\ppath$ is the path $\edgeGstar{(S,P)}{u}{v}{\Graph}$ then we say that $\tau$ progresses in $(S,P)$ if 

\begin{definition}[Global Trace Condition - GTC]\label{def:GTC}
The transition graph $\Graph$ satisfies the {\em Global Trace Condition} if for all infinite path $\ppath$ of $\Graph$ there is an infinite trace $\tau$ such that
$\tau \models \ppath$, which has infinitely many progress points.
\end{definition}

\medskip Here we introduce the system $\CLKIDomega$ and its particular case $\CLJIDomega$, and show that our GTC is the same as the correctness condition in \cite{BrotherstonSimpson}.

Using \cite{Mirai}, we argue that GTC = SCT.

\subsection{Injective bi-partite relations}
\label{subsec:injective}

In general, a relation $R \subseteq X \times Y$ is {\em injective} if for all $x,x' \in X$ and $y \in Y$, $xRy$ and $x'Ry$ implies $x = x'$.
Equivalently, $R$ is injective if all the $R(x)$ for $x \in X$ are disjoint.

\begin{lemma}\label{lem:comInjective}
If both $R \subseteq X \times Y$ and $R' \subseteq Y \times Z$ are injective, then $RR' \subseteq X \times Z$ is injective.
\end{lemma}

\begin{proof}
If $xRR'z$ and $x'RR'z$ then there are $y,y' \in Y$ such that $xRy$ and $yR'z$, and $x'Ry'$ and $y'R'z$. By the injectivity of $R'$ we have $y = y'$,
hence $x = x'$ by the injectivity of $R$.
\end{proof}

We say that $(S, P)$ is {\em injective} if $|(S, P)| = S \cup P$ is such in the above sense.

\begin{lemma}\label{lem:biRelInjectiveComp}
If both $(S,P)$ and $(S',P')$ are injective, then $(S,P) \comp (S',P')$ is injective.
\end{lemma}

\begin{proof}
By (\ref{eq:unionComp}) in Section \ref{sec:size-change},  we know that $|(S,P) \comp (S',P')| =  |(S,P)| |(S',P')|$ which is ordinary composition of the injective reations $S \cup P$ and $S' \cup P'$, hence it is injective by Lemma \ref{lem:comInjective}.
\end{proof}

In case of injective bi-partite relations, composition can be simplified by:
\[ (S,P) \comp (S',P') = (SS', SP' \cup PS' \cup PP') \]
Indeed, by injectivity if $xSyS'z$ then $y \not \in \cod{P} \cup \dom{P'}$ hence $(x,z) \not \in ( SP' \cup PS' \cup PP')$.

\medskip
We say that the set of bi-partite relations $\biRel$ is {\em injective} if all $(S,P) \in \biRel$ is such. By Lemma \ref{lem:biRelInjectiveComp}, if $\biRel$
is injective then $\biRel^*$ is such. If $\Graph = (V, \biRel, E)$ with injective $\biRel$, by abuse of language we say that $\Graph$ is injective.

Then we prove:
\begin{theorem}
If $\Graph_\Pi$ is the transition graph associated with a cyclic proof $\Pi$ of $\CLKIDomega$, then $\Graph_\Pi$ is injective.
\end{theorem}
