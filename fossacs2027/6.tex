\section{Conclusion}

We have proposed a novel notion of domain-stable sequences and
we have defined the weight for a domain-stable sequence, which 
decreases when a computation goes with the sequence.
By using the weight, we have defined a ranking function under the
size-change termination condition and the fan-in-free condition.
For defining ranking functions and proving
correctness of them, we have given a simple and intuitionistic proof.

By using the intuitionistic ranking function synthesis,
we have given an intuitionistic proof transformation
from intuitionistic first-order cyclic proof system $\CLJIDHA$
with Heyting arithmetic
into intuitionistic first-order inductive proof system $\LJIDHA$
with Heyting arithmetic.
