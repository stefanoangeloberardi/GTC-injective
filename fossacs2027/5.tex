\section{Intuitionistic Proof Transformation}

This section proves the induction principle for path relation,
and by using it this section defines intuitionistic proof transformation
from $\CLJIDHA$ to $\LJIDHA$ with its correctness proof in intuitionistic logic.

\subsection{Induction Principle for Path Relation}

This section proves the induction principle for path relation.

For a given cyclic proof, we assign a differenct number to each companion
in it and we call the number a {\em companion number}.
We write $\Gamma_{2i} \prove \Delta_{2i}$ for the sequent of
companion number $i$.
We call a path from a companion to a bud a {\em companion-bud path}.

For a sequence $\Gamma$ of formulas,
we write $||\Gamma||$ for the number of inductive atomic formulas in $\Gamma$.
We write $||\Gamma \prove \Delta||$ for $||\Gamma||$.

\begin{Def}\rm
Assume a finite composition $\pi$ of companion-bud paths in 
the infinite unfolding of a given cyclic proof $\Pi$.

We define
$\NPT_\pi(q_1,q_2)$ to hold if
there is some progressing trace from the $q_2$-th atomic formula in 
the bottom sequent of $\pi$
to the $q_1$-th atomic formula in the top sequent of $\pi$.
We define
$\PT_\pi(q_1,q_2)$ to hold if
there is some non-progressing trace from the $q_2$-th atomic formula in 
the bottom sequent of $\pi$
to the $q_1$-th atomic formula in the top sequent of $\pi$.

we define $\tilde>_{\pi}$ by
\[
x \tilde>_{\pi} y \equiv
|x|=|J_2| \land |y|=|J_1| \land
\\ \qquad
\Land_{\NPT_\pi(q_1,q_2)} (x)_{q_2} > (y)_{q_1}
\land
\Land_{\PT_\pi(q_1,q_2)} (x)_{q_2} = (y)_{q_1}
\]
where 
$J_1$ and $J_2$ are the top and bottom sequents of $\pi$ respectively.

Define $x >_{\pi} y$ by
$
x >_{\pi} y \equiv
(x)_0=j \land (y)_0=i \land  (x)_1 \tilde>_{\pi} (y)_1
$
where 
$J_{2i}$ is the top sequent of $\pi$ and
$J_{2j}$ is the bottom sequent of $\pi$.

We define
$>_\Pi$ as \Break
$\bigcup \{ >_\pi \ |\ \hbox{\small $\pi$ a finite composition of
companion-bud paths in the infinite unfolding of $\Pi$} \}$.
\end{Def}

For $\rho$ obtained in Theorem \ref{th:rankingfunc},
we define $\rho'(c,x)$ as
$\rho(c,((x)_0,\ldots,(x)_{l-1}))$
where $J$ is the sequent of companion number $c$,
and $l=||J||$.

The next proposition says that
if a stage-number decreases
then
a ranking function decreases.

\begin{Prop}\label{prop:0.5}
For a bud-companion path $\pi$ from a companion $c$ to a bud $d$
in a given cyclic proof,
$(c,x) >_\pi (d,y)$ implies $\rho'(c,x) >_\Lex \rho'(d,y)$.
\end{Prop}

{\em Proof.}
In a given cyclic proof $\Pi$,
we write $\pi_i$ for the a companion-bud path from 
the companion number $c_i$ to the companion number $d_i$ with $i \in I$.

For $\pi_i$, we define an SC graph $G_{\pi_i}$ 
as $(c_i,(S_i,P_i),d_i)$ where
$j S_i l$ is defined to hold if $\NPT_{\pi_i}(j,l)$, and
$j P_i l$ is defined to hold if $\PT_{\pi_i}(j,l)$.

The SC call graph consisting of
the set $\{G_{\pi_i} \ |\ i \in i\}$ of SC graphs satisfies the SCT condition.
It is shown as follows.
Assume an infinite composable sequence $G_{\pi_{p_1}},G_{\pi_{p_2}},\ldots$
of SC graphs.
Then $\pi_{p_1},\pi_{p_2},\ldots$ is an infinite path 
in the infinite unfolding of the cyclic proof $\Pi$.
By the global trace condition, there is some trace for some tail of the path
that is infinitely progressing.
Let $A_1,A_2,\ldots$ be the occurrences of the inductive atomic formulas
in the trace.
Take $n_i$ such that
$A_i$ is the $n_i$-th inductive atomic formula in the antecedent.
Then $n_1,n_2,\ldots$ is an SC trace of some tail of $G_{\pi_{p_1}},G_{\pi_{p_2}},\ldots$ that is infinitely progressing.
Hence the SC call graph satisfies the SCT condition.

By Theorem \ref{th:rankingfunc}, there is some $\rho$ such that
$(c,\Vec t) \to^{G_i} (d,\Vec u)$ implies
$\rho(c,\Vec t) >_\Lex \rho(d,\Vec u)$.

Fix a companion-bud path $\pi$ from a companion $c$ to a bud $d$ and
assume $(c,x) >_\pi (d,y)$.
Then $(x)_i > (y)_j$ iff there is a progressing trace from $i$ to $j$
iff $i P j$.
Moreover $(x)_i \ge (y)_j$ iff there is a non-progressing trace from $i$ to $j$
iff $i S j$.
Hence we have
\[
(c,((x)_0,\ldots,(x)_{l-1})) \to^{G_\pi} (d,((y)_0,\ldots,(y)_{l'-1}))
\]
where $J_2$ and $J_1$ are 
the bottom sequent and the top sequent of $\pi$ respectively,
and $l=||J_2||$ and $l'=||J_1||$.

By the ranking function $\rho$, we have
$\rho(c,((x)_0,\ldots,(x)_{l-1})) >_\Lex \rho(d,((y)_0,\ldots,(y)_{l'-1}))$.
Hence $\rho'(c,x) >_\Lex \rho'(d,y)$.
$\Box$

The proposition can be extended from a path to a composition of paths
in the next proposition.
The proof is given in the appendix.

\begin{Prop}\label{prop:1}
For a given cyclic proof $\Pi$,
$(c,x) >_\Pi (d,y)$ implies $\rho'(c,x) >_\Lex \rho'(d,y)$.
\end{Prop}

For a companion number $j$ in a given cyclic proof,
we define
\[
G_jx \equiv \forall \Vec z(
((x)_0,\ldots,(x)_{l-1}) = \Vec v \imp
(\Gamma_{2j})^\circ_{\Vec v} \imp \Delta_{2j}^\bullet), \\
Gx_0x \equiv \Land_{j \in K} (x_0=j \imp G_jx),
\]
where 
$l = ||\Gamma_{2j}||$, and
$\Vec z$ is $\FV((\Gamma_{2j})^\circ_{\Vec v},\Delta_{2j}^\bullet)$.

The next proposition is proved by induction on $<_\Lex$
in a straightforward way.
The proof is given in the appendix.

\begin{Prop}\label{prop:2}
\[
\HA \prove 
\forall cx(\forall dy(\rho'(d,y) <_\Lex \rho'(c,x) \imp Gdy) \imp Gcx)
\imp \forall cx.Gcx.
\]
\end{Prop}

\begin{Prop}\label{prop:ind}
$\HA \prove \Ind(>_\Pi,G)$.
\end{Prop}

{\em Proof.}
In the statement of Proposition \ref{prop:2},
since $\rho'(d,y) <_\Lex \rho'(c,x)$ appears negatively,
by Proposition \ref{prop:1}, we can replace it by $(d,y) <_\Pi (c,x)$.
Hence $\Ind(>_\pi,G)$ is provable.
$\Box$

\subsection{Proof Transformation from Cyclic Proofs to Inductive Proofs}

By using the induction principle for path relation,
this section defines intuitionistic proof transformation
from $\CLJIDHA$ to $\LJIDHA$ with its correctness proof in intuitionistic logic.

The following proposition gives
proof transformation
assuming the induction principle for path relation.

\begin{Prop}[Proof Transformation Assuming Induction Principle]
Assume the induction principle $\Ind(>_\Pi,G)$.
If $\CLJIDHA$ with inductive predicates $P_1,\ldots,P_n$ proves a sequent,
then there is a proof of the same sequent in $\LJIDHA$ with $P_1,\ldots,P_n$ and their stage-number inductive predicates $P_1',\ldots,P_n'$.
Moreover, we have an algorithm of
proof transformation from $\CLJIDHA$ to $\LJIDHA$.
Moreover, the correctness of the algorithm is proved in intuitionistic logic.
\end{Prop}

{\em Proof.}
The proof transformation and its correctness are given
in the proof of Theorem 4.4 in \cite{Berardi18}.
They are given in Sections \ref{sec:stagenumber}
and \ref{sec:prooftrans} of the appendix (Proposition \ref{prop:assumeInd}).
We can also say the meta-theory is intuitionistic
by carefully reading the proof.
$\Box$

Note that to show the induction principle for path relation,
\cite{Berardi17a} used Ramsey theorem and
\cite{Berardi18} used Kleene-Brouwer theorem.
Instead we use domain-stable sequence for it.

Combining Proposition \ref{prop:ind} and
this proposition,
we obtain the following theorem.

\begin{Th}[Proof Transformation from $\LJIDHA$ to $\CLJIDHA$]
If $\CLJIDHA$ with inductive predicates $P_1,\ldots,P_n$ proves a sequent,
then there is a proof of the same sequent in $\LJIDHA$ with $P_1,\ldots,P_n$ and their stage-number inductive predicates $P_1',\ldots,P_n'$.
Moreover, we have an algorithm of
proof transformation from $\CLJIDHA$ to $\LJIDHA$.
Moreover, the correctness of the algorithm is proved in intuitionistic logic.
\end{Th}
