\section{Size-Change Graphs}

This section gives background for size-change graphs and
ranking functions.

\subsection{Size-Change Termination}

This section gives background for size-change graphs.

\begin{Def}[Function Symbols]\rm
We assume every function symbol comes with its arity.
We define $\Functionnames$ as the set of function symbols and
we define $\arity : \Functionnames \to N$.
\end{Def}

For simplicity, we write SC for "size-change".

\begin{Def}[SC Call Graph]\rm
For given $\Functionnames$ for function symbols,
an SC call graph is defined to a labeled graph $(V,E)$ where

vertexes $V \subseteq \Functionnames$,

edges $E \subseteq \{(f, (S, P), g) \ |\ 
f,g \in \Functionnames,
S, P \subseteq [1,\arity(f)] \times [1,\arity(g)],
S \cap P = \emptyset \}$,
where the graph is a directed graph with edges and
the edge $(f, (S, P), g)$ is from the vertex $f$ to the vertex $g$.

For simplicity, we defined $V \subseteq \Functionnames$, but
formally $V$ 
can be defined as a finite set of points
with a labeling function
$
L : \hbox{(the finite set)} \to \Functionnames.
$
A similar formal definition can be applied to $E$.

We will often write $G_i$ for an edge in $E$.
%
A path is defined as a consecutive sequence of edges in $E$ as usual.
A path may be infinite.

We call an edge in an SC call graph an {\em SC graph}.
An SC call graph represents a bipartite graph such that
the first set of its vertexes are arguments of the calling function, and
the second set of its vertexes are arguments of the called function, and
the edges are the collection of
an edge from the $i$-th argument of the calling function to
the $j$-th argument of the called function with the edge label $S$
for $i S j$,
and
an edge from the $i$-th argument of the calling function to
the $j$-th argument of the called function with the edge label $P$
for $i P j$.

We call a path in an SC call graph an {\em SC path}.
%
For a given finite SC path $(G_1,\ldots,G_k)$,
an {\em SC trace} in the path is defined to be
a finite sequence $(n_1,\ldots,n_k)$ of natural numbers such that
$n_i (S_i \cup P_i) n_{i+1}$ for all $i \in [1,k-1]$
where $G_i = (f_i,(S_i,P_i),f_{i+1})$.
For an infinite SC path,
an SC trace of the path is defined similarly,
where the SC trace is infinite.
%
An SC trace $(n_1,\ldots,n_k)$ is called progressing
if there is some $i \in [1,k-1]$ such that
$n_i P_i n_{i+1}$.
The SC trace is called non-progressing otherwise.
\end{Def}

For simplicity, we sometimes write $-$ to denote
an implicit existential for
something not related to discussions.

\begin{Def}[Infinitely Progressing SC Trace]\rm
An infinite SC trace is defined to be {\em infinitely progressing}
if there are infinitely many $i \in N$ such that $n_i P_i n_{i+1}$
where
the SC trace is an SC trace $n_1,n_2,\ldots$ of 
a infinite SC path $G_1,G_2,\dots$
and $G_i=(-,(S_i,P_i),-)$ for all $i \in N$.
\end{Def}


An edge $(f, (S, P), g)$ corresponds to
a size-change graph $G : f \to g$ in \cite{Ikebuchi25}
where
\[
x_i^f {\displaystyle \mathop{\to}^\downarrow} x_j^g \hbox{ if } iPj, \\
x_i^f {\displaystyle \mathop{\to}^{=\hskip -5pt\downarrow}} x_j^g \hbox{ if } iSj.
\]

The relation $S$ means a stationary relation, and
a non-progressing SC trace in the definition
corresponds to a non-progressing trace in \cite{Brotherston11}.
The relation $P$ means a progressing relation, and
a progressing SC trace in the definition
corresponds to a progressing trace in \cite{Brotherston11}.

\begin{Def}[Size-Change Termination Condition]\rm
An SC call graph is defined to satisfy size-change termination condition if
for any infinite SC path $G_1,G_2,\ldots$ in the SC call graph
there are some $k \in N$ and an infinitely progressing SC trace $n_k,n_{k+1},\ldots$
in the SC path $G_k,G_{k+1},\ldots$.
\end{Def}

We write SCT for "SC termination."

\subsection{Ranking Functions}

This section gives background for ranking functions.

We will sometimes write a sequence $v_1,\ldots,v_k$ for $\Vec v$.
We write $(v_1,\ldots,v_k)_i$ for $v_{i+1}$ with $i \ge 0$.

\begin{Def}[State]\rm
For a given $\Functionnames$,
a {\em state} is defined to be $(f,\Vec v)$
where $f$ is in \Functionnames\
and $\Vec v \in N^{\arity(f)}$.

For a given SC call graph,
an SC graph $G$ and
states $(f, \Vec v)$ and $(g, \Vec w)$,
we define $(f, \Vec v) \to^G (g, \Vec w)$ to hold if
$G=(f,(S,P),g)$ and
for all $i \in [1,\arity(f)]$ and $j \in [1,\arity(g)]$,

- $v_i \ge w_j$ if $i S j$, and

- $v_i > w_j$ if $i P j$.
\end{Def}

When the function $f$ calls the function $g$,
a computation from the state $\Vec v$ to $\Vec w$ is overapproximated by
$(f, \Vec v) \to^G (g, \Vec w)$.

\begin{Def}[Ranking Function for SC Call Graph]\rm
For a given SC call graph,
a function $\rho$ is defined to be a ranking function for the SC call graph if
for some $m$, we have
$\rho: \hbox{states} \to (N \cup \{\infty\})^m$
such that

- if $(f, \Vec v) \to^G (g, \Vec w)$
then $\rho(f, \Vec v) >_\Lex \rho(g, \Vec w)$,

\noindent
where $>_\Lex$ is the lexicographic order on $(N \cup \{\infty\})^m$.
\end{Def}

The following theorem of ranking function synthesis are discussed 
in Theorem 4.11 \cite{Lee09} and Theorem 3.3 \cite{Benamram09} and
Theorem 6.17 \cite{Benamram10}.

\begin{Th}
If an SC call graph satisfies SCT condition,
there is an algorithm to synthesize a ranking function
for the SC call graph.
\end{Th}
Note that \cite{Benamram09} assumed a fan-in free condition.

The metatheory of all these papers is classical and they use complicated results such as Ramsey Theorem or Buchi Automata.

In this paper, 
by assuming injectivity condition, which is the same as the fan-in free condition,
we will provide a more direct proof for the same statement in
Intuitionistic Arithmetic.
